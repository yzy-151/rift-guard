# 裂隙守望 · Rift Guard

> 怎么样旅行者，来壶开水充充饥吧
>
> ——芙宁娜，第一次见面

一款能把旅行者、坚果墙和丘丘暴徒放在同一条路上的实时小队塔防。芙宁娜拎着水壶来找你，格温已经在前线，左边还有一颗水晶要守。角色会自己攻击，你来决定谁上场、钱花在哪一格，以及 Boss 抬手时全队该往哪躲。

## 第一次出发

选关后先看过场、接对话，再编队上场。新档从旅行者独自出发，芙宁娜会在第一关的出发剧情里遇见你。第一关场上还有一位临时帮手格温，这时选人页里没有她。守住前哨，完成战后的招募对话，她才成为下一关能带走的队友。

![芙宁娜从打招呼到递上开水，两个回答出现在对话框里](docs/media/readme/first-meeting.gif)

试玩依次开放 **裂隙前哨 → 赤潮回廊 → 黑曜母巢**。选关页能看到全部八关，第 4 至 8 关在此版锁定。继续下一章会重新选卡。在结算页转入无尽，可以带走这局已经成形的队伍和卡牌。

## 一条防线怎么搭起来

| 战场上发生了什么 | 你能做什么 |
| --- | --- |
| 敌人沿几条路线走向左侧水晶 | 从底栏拖角色上场，守交汇处。地面敌人可以拦，小蝙蝠会从头顶飞过，要给能对空的队友留一个位置。 |
| 击杀带来金币 | 在商店选机关，再点空格部署。普通关每格放一个机关，同时最多 25 个。向日葵每 8 秒产 20 金币，钱紧时也可以先买坚果堵路。 |
| 坚果开始开裂，敌群挤进同一行 | 豌豆沿本行向右直射，西瓜在落点造成范围伤害。土豆雷埋下 3 秒才武装，提前一格种才来得及。 |
| 水晶升级，弹出三张卡 | 看眼场上的东西再选。抽到「双发射手」，已经种下的豌豆也会双发。「铁坚果」让现有坚果和之后种下的坚果都获得 2.5 倍最大生命与 30 护甲。 |

### 水晶升到 9 级，这一手拿什么？

![两次实际三选一，依次展示征服者、狂徒铠甲、纳什之牙，以及幻影之舞、兰顿之兆、幽灵疾步](docs/media/readme/card-draft.webp)

动图里是从同一版本卡池抽到的两手牌。第一手很适合拿来分工。前排已经在掉血，「狂徒铠甲」每 5 秒回血。站得住又能一直出手，就让「征服者」打满六击，拿增伤和击中回血。想让后排更快清兵，「纳什之牙」一级就有 28% 攻速和普攻追击。

第二手是「幻影之舞」「兰顿之兆」「幽灵疾步」。上路漏怪时，幻影之舞兼顾攻速和移速。需要有人站稳吃伤害时，兰顿加防御与生命上限。总要在两路之间救火的角色，可以拿幽灵疾步的 60 点移速。

## 前两关的三位同伴

### 旅行者 · 元素由这局的卡决定

初始拿剑上场，Q 是「无锋回旋」，E 是「星落裁决」。抽到元素卡会换整套技能。下图是岩系，Q「荒星」可以直接砸在敌人前面，留下一颗有生命值的落岩拦住地面部队，场上最多同时有三颗。E「群山回响」向外打出四道震波，并给全队加共享护盾。

![岩系旅行者在敌群中落下荒星，接着释放群山回响](docs/media/readme/traveler.gif)

同一个路口也能换一种打法。雷系 Q「雷索逐星」最多串起九个不同目标，敌人走到一起时出手最划算。水系 Q「涌泉恩典」能边打边给范围里的队友回血，适合让守路口的人多扛一波。

### 芙宁娜 · 把交火处变成舞台

Q「孤心沙龙」在指定位置展开 12 秒，三位沙龙成员各有自己的射速和水弹溅射范围。把舞台摆在两路汇合处，敌人经过时就会被轮番点名。芙宁娜自己的普攻还能对空，第一关遇到小蝙蝠时尤其有用。

![芙宁娜在敌群中布置沙龙，三个成员轮流开火，随后随身舞台展开](docs/media/readme/furina.gif)

E「万众狂欢」开幕时造成水伤，接下来的 12 秒舞台会跟着芙宁娜移动。圈内队友伤害提高 **35%**，每 2 秒回血一次。前排为了躲 Boss 换位置，记得让她也跟上。

### 格温 · 五秒免伤，十五根针

Q「丝缕缠流」保护施放时在她攻击范围内的队友，获得 **5 秒免伤**。先把格温站到能罩住两人的位置，再等 Boss 技能读条。E「引针簇射」朝选定方向连发三轮，每轮五根，针能贯穿并让敌人减速 2 秒。站在队伍侧面，沿着长长一列怪物瞄准，一次能照顾好几个。

![格温张开保护范围，随后朝一排敌人发射多轮贯穿针](docs/media/readme/gwen.gif)

## 第三关通关后可以编入队伍的四位角色

### 阿米娅 · 先挂黑晶，再开奇美拉

Q「精神爆发」向选定区域打出六枚追踪黑晶，在最近的至多三个敌人之间分配。每次命中会留下持续 8 秒的印记，同一目标最多三层。E「奇美拉」消耗阿米娅自身 8% 最大生命，造成两次震击和一次终击。每层印记让终击额外增伤 30%。想打单体爆发，可以先清掉精英身边的小怪，让黑晶都落在它身上。

![阿米娅先打出追踪黑晶，随后奇美拉在怪群脚下连续震击](docs/media/readme/amiya.webp)

### 风堇 · 用风刃把三排敌人往回推

Q「风刃切流」以风堇所在行为中心，从上到下每隔 1 秒扫一排。风刃横穿战场，命中的敌人退一格。两路怪快要汇合时，把风堇挪到它们中间那一行再开 Q。E「长风复苏」是留在落点的治疗区，持续 12 秒，每 0.85 秒回一次血。图里的旅行者已经掉血，治疗区就铺在他脚下。

![风堇逐行推出风刃，随后在受伤的旅行者脚下展开绿色治疗区](docs/media/readme/hyacine.webp)

### 洛琪希 · 一次急救，一片雷云

Q「水脉疗愈」可以直接点受伤队友脚下，当场治疗范围内的友军。E「豪雷积层云」先在落点打出水伤，再留下持续 9 秒的雷云，反复打击区内敌人并连锁到邻近目标。把云留在坚果或前排身前，刚刚补满血的队友就能把敌人留在云底下。

![洛琪希在队友身边施放治疗，再将豪雷积层云放到怪群经过的位置](docs/media/readme/roxy.webp)

### 丰川祥子 · 让敌人退回火场

Q「灼热乐章」用火元素音浪击退敌人，在落点留下 5 秒燃烧地面。E「焰色交响曲」范围更大，燃烧持续 10 秒，还会提升全队暴击率。遇到前排快要被挤穿的一波，瞄准敌人脚下开 Q，等后续队伍走到同一条路再交 E。

![丰川祥子的灼热乐章把近处敌人推开，焰色交响曲随后覆盖更大的区域](docs/media/readme/sakiko.webp)

## 第一关 · 裂隙前哨 / 史莱姆王

| 丘丘斧王（图鉴名「丘丘暴徒」） | 源石虫 |
| --- | --- |
| ![丘丘暴徒进入攻击姿态，加速逼近旅行者后挥斧](docs/media/readme/axe-mitachurl.webp) | ![源石虫被远程击倒，红圈收紧后死亡爆炸，旁边两只丘丘人一起掉血](docs/media/readme/originium-blast.webp) |
| 靠近角色后会切换攻击姿态，移速翻倍。让前排先接住，给远程队友留出输出位置。 | 击倒后等约 1 秒才炸，爆炸会同时伤到圈内的角色和怪物。动图里芙宁娜在圈外击倒它，两只跟上来的丘丘人一起吃到了伤害。 |

**5 分 45 秒，史莱姆王登场。** 王冠底下除了血条还有护盾。生命降到一半时，它会回盾、叫出援兵，技能也出得更快。下面先是「王冠弹跳」，接着是「五色黏爆」。看地面就能分清哪一招打完还不能站回去。

| 吞噬回流 | 它把近处的角色拉回身边，每多命中一人就多回一份盾。看见招名，优先把贴身的人拉走。 |
| 分裂王庭 | 残像分别冲向预告点。第二阶段还有一下以本体为中心的爆炸，躲过残像后稍等再贴脸。 |

## 无尽生存

小队走出固定防线，在移动的安全区内边走边打。任务按生存时间成批刷新。「回收补给」要走到三只金色补给箱旁拾取，报酬是恢复生命。「击败首领」则能拿两次选卡并回血。补给、下一处安全区和正在逼近的敌群，往往分在三个方向。

![无尽生存中小队沿街移动作战，画面同时显示区域地图和当前任务](docs/media/readme/endless-run.gif)

**无尽重敌 · 皮卡超人。** 它带盾接近，出手慢、单击很重。下图能看到旅行者先打在盾上，随后破盾才打进血条。前排已经吃过一刀时，把人拉开，比留在原地换第二刀划算。

![无尽场地里的皮卡超人举剑劈下，旅行者连续进攻击破护盾](docs/media/readme/pekka.webp)

## 家园 · 裂隙客厅的三扇门

从主菜单进家园，就能直接在客厅里走动。已解锁的同伴会出现在屋里，走到相邻格按 **F** 可以聊天。同一个人有多段日常对话，遇到二选一时由你接话。家具也有用。「出门打架」打开选关，「翻翻档案」打开图鉴，「荣誉柜」查看成就，「滑动变阻器」进入设置。

![从家园客厅走进搬家练习，绕到箱子背后推动它](docs/media/readme/home-puzzle.gif)

客厅三扇门各通向三间房，共九张谜题地图。过关会记录进度，再从同一扇门出发，可以接着走这条路上还没解开的房间。

| 从哪扇门进 | 接下来的房间 | 路上要留意什么 |
| --- | --- | --- |
| 搬家练习 | 茶歇搬运工 → 深夜值班 | 第一间只有一个箱子，适合练习从哪侧下手。到了茶歇搬运工，箱子变多，终点还能遇见阿米娅。 |
| 扎脚舞池 | 潮汐绕行 → 王座散步 | 地刺会随回合起落。潮汐绕行要在箱子和地刺之间找路，通关后可以留下来和芙宁娜说话。 |
| 邻居有意见 | 剪刀与石头 → 最后一把钥匙 | 骷髅挡路时，朝它走能踢它一脚，但人会留在原格。计算拿钥匙的路线时，把踢击消耗的步数也算进去。 |

每次走格、推箱、踢击或原地等候都用掉一步。踩中升起的地刺会额外扣两步。拿钥匙后再去出口，最后一步抵达也算通关。**空格**等一拍，**Z** 撤回刚才那步，**R** 重来。到有同伴的终点，按 **F** 聊天，按 **Enter** 去下一间。

![潮汐绕行实机，推箱穿过地刺区，抵达出口后与芙宁娜交谈](docs/media/readme/home-visit.webp)

## 下载与操作

Windows x64 下载 `RiftGuard.exe`，双击直接玩。Android 下载 `RiftGuard-Android.apk`，安装后横屏游玩，支持 arm64-v8a 和 x86_64。[Windows 下载](https://github.com/yzy-151/rift-guard/releases/latest/download/RiftGuard.exe) · [Android 下载](https://github.com/yzy-151/rift-guard/releases/latest/download/RiftGuard-Android.apk)

| 操作 | Windows | Android |
| --- | --- | --- |
| 上场 | 把底部角色卡拖到战场 | 按住角色卡拖到战场 |
| 移动 | 选中角色，右键点地或用 WASD | 点「移动」或「全队移动」，再点地面 |
| 技能 | Q / E，指向性技能再选位置或方向 | 点技能按钮，按提示点目标 |
| 机关 | 顶部商店选种类，再点空格 | 点种类，再点空格 |
| 暂停 / 全屏 | 空格或 Esc 暂停，F11 切换全屏 | 暂停按钮或系统返回键，横屏全屏 |
| 家园 | WASD 或方向键行走，F 交互 | 屏幕方向键和交互按钮 |

游戏使用 Godot 4.4.1 和 Compatibility 渲染器。源码入口是 [game/project.godot](game/project.godot)，导出环境和安卓验证范围见[试玩版发行说明](docs/release-20261121.md)。文中画面均录自 Windows 试玩版。角色、怪物与 Boss 的近景采用固定遭遇演示动作。两手联盟牌选自正常卡池的不同随机种子。
