- `01_mondstadt_background_1920x1080.png`：1920×1080 蒙德远景。城门、风车和群山位于远景层，下半部预留连续草地衔接区。
- `02_grass_grid_ground_32x18_topdown.png`：完全俯视 32×18 草地正方格，共 576 格，每格 60×60 像素；颜色从背景近处草地取样校准。

## 拼接基准

- 1920×1080 战斗画面中，将格子地图透视后的远端边放在 `Y≈505`，左右端约为 `X=305` 与 `X=1615`。
- 远端向下约 48 像素做透明度渐入，可与背景草地自然交接；该渐变只用于渲染组合，不修改寻路网格。
- 背景和格子地面已使用同一黄绿色草地色域，避免旧版的荧光绿断层。

## Godot 使用建议

- 背景放在最底层 `Sprite2D`，按 1920×1080 显示。
- 格子源图保持无透视标准矩形，游戏中由相机、Shader 或四点变换呈现 2.5D；碰撞、寻路继续使用 32×18 逻辑网格。
- 可在格子层 Shader 顶端加入约 4% 画面高度的 alpha feather，使远景衔接不露硬边。
- 所有独立设施素材保留 Alpha，碰撞与玩法区域请在 Godot 中单独配置。
