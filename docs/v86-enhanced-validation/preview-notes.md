# 战斗动态演示与特效验证

`combat-preview.mp4` 是 Godot 4.6 实际渲染和战斗模拟的约 24 秒演示，1920×1080、30 FPS，保留 V86 红黑 HUD、角色与怪物素材、角色技能及技能图标。截图直接来自同一次运行。

这是**自动布置的战斗演示，不是普通流程通关或平衡性测试**。录制预设水晶等级 5、雷元素旅行者和起始大招能量，按时间逐个部署洛琪希、哥伦比亚并安排怪物出现。普通关卡波次和契约结算被推迟到片段结束之后，以免庆祝横幅遮住动作。人物及怪物伤害、移动、攻击、技能冷却、元素反应、怪物死亡与源石虫延迟爆炸仍由实际战斗模拟执行；没有把伤害或击败动画剪贴到画面上。

片段包括雷元素连锁与三相雷狱、洛琪希积层云落雷、敌方箭矢和风弹、击败烟团、出场漩涡，以及原有源石虫、蝙蝠、灰色旋转大丘丘人的战斗。展示期间没有持续打开角色范围预览，保留地面危险预警。

可复跑的测试位于 `game/tests/qa_comic_combat_vfx.gd`。在工程目录运行：

```powershell
& 'C:/Users/yzy/Desktop/codex/tools/godot-4.6/Godot_v4.6-stable_win64_console.exe' --headless --path game --script res://tests/qa_comic_combat_vfx.gd -- --qa-output=C:/Users/yzy/Desktop/codex/rift-guard/recheck/vfx
```

`--qa-output` 将验证存档隔离到任务缓存目录。无窗口运行包含 15 项检查；真实窗口运行时保留该参数，并追加 `--capture-dir=绝对输出目录`，可包含 20 项检查及截图：

- 2000 个击败事件限制在 72 个漫画瞬时效果，低效果模式收敛至 28 个；过期后全部归还池，1932 次复用。
- 500 个走提前返回分支的雷击事件仍遵守统一效果上限。
- 命中停顿请求只消费一次，切换场景时清空。
- 顶部角色越界与受击震动时，场地外区域不覆盖 HUD 间隙。
- 史莱姆多段落点在来源冻结 2.8 秒、施法动画已结束后仍按实际 `hazard.delay` 保留预警；解冻命中后移除待释放预警。

测试脚本只创建验证场景，不修改剧情、角色配置或存档。录像脚本、原始 AVI、日志及其余验证截图保留在本机任务缓存目录，正式 MP4 与精选截图位于本目录。
