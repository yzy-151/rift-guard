# Rift Guard V65

V65 集中修复 V64 可维护性重构引入的战斗运行回归。

## 修复

- 修复普通关卡怪物生成后停止运行、表现为关卡不出怪的问题。
- 修复无尽模式怪物无法移动的问题。
- 修复角色普通攻击弹道、角色攻击特效和怪物攻击特效不再出现的问题。
- 修复丘丘射手锁定后可在射程外完成攻击的问题。
- 修复同一个 11×20 地砖被多个地形效果重复占用、贴图互相重叠的问题。
- 非飞行怪物生成在阻挡区域时会自动移动到最近的可通行位置。

## 根因

V64 的正交寻路重构把未标注类型的数组直接赋给 `Array[Vector2]`，Godot 在每次怪物更新时抛出运行时类型错误并中断后续战斗处理。V65 改为显式构建类型数组，同时补齐射程结算和地形占格约束。

## 校验

- V65 战斗定向回归：14 / 14 通过。
- 普通关卡 01–08：全部通过出怪与移动检查。
- 无尽模式：通过生成与移动检查。
- 双方弹道、攻击事件与战斗画面特效接收：全部通过。
- 丘丘射手射程内外行为：全部通过。
