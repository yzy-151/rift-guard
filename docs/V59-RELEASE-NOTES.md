# Rift Guard V59

V59集中重做战斗与剧情界面，并保持V58的性能和战斗逻辑改进。

## 主要变化

- 顶部HUD改为58px内部高度的连续状态带，信息按品牌、构筑进度、关卡状态和基地状态分组。
- 普通模式怪物数量/下一波倒计时改为208×25的小型中央徽标。
- 底部HUD改为118px内部高度的单层指令台，队伍、战技/终结技、队形与构筑信息分区排列。
- 角色卡、选队确认按钮、剧情选项框和Boss警告框采用等比例TextureRect，不再扭曲端点装饰。
- 错误剧情选项播放Helltaker九帧死亡序列，显示死亡原因，结束后返回原选项。
- 无尽模式新增8种Helltaker实验室地板和Boss契约地板拼接。
- Boss预出场警告停留时间由0.82秒提高到1.85秒。
