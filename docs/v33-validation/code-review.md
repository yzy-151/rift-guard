# V33 代码审查结论

审查范围：远征检查点、主流程生命周期、菜单继续入口、事件结算、幸运跨关、失败重开、无尽隔离与发布验收。

- 检查点采用版本 33 双槽轮换、SHA256 摘要和字段/内容 ID 校验；恢复前完成验证，最新槽损坏时可回退上一份有效记录。
- 保存编队、关卡、种子、路线、裂隙币、遗物、远征幸运、增益、关系、剧情标志和奖励账本；战斗内敌人、弹道与卡牌层数不写入。
- 关前剧情、战斗起点、通关结算、路线和待选事件均有明确恢复路径；失败不会发放奖励，无尽模式不会覆盖战役检查点。
- 保存失败显示在所有全屏界面之上且不拦截鼠标输入；下一次成功保存会清除提示。
- 完整 UI 专项在 1280×720、1600×900 与主分辨率 1920×1080 下通过主菜单、设置、普通模式、关卡、编队、对话选项、拖拽部署、主动技能、终结技、三选一、暂停页和无尽模式。
- 未发现阻断发布的问题；V34 范围未混入本次实现。
