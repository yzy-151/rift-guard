# Rift Guard V13：神格与幸运

## 本次完成

- 剧情模式三名场上角色均可在完整战场区域移动，不再受左侧防区限制。
- 无尽生存的升级主体明确为旅行者，卡池剔除水晶生命与修复卡，界面不再显示水晶升级文案。
- 新增幸运属性与三张幸运卡；幸运会降低普通卡相对权重，并逐级放大稀有、史诗、传奇、神话权重。
- 在传奇之上新增“神话”档；每 10 级至少出现一张神话卡，其他等级仍可通过幸运提前抽到。
- 新增四张神话卡：双界共鸣、万象弹幕、碎界、永恒终幕。
- 双界共鸣让旅行者同时持有两种元素，普通攻击连续附着双元素，主动技能追加第二元素爆发。
- 水晶加固卡现在真实增加基地最大生命，HUD、血条与通关评级同步读取新上限。
- 全部普通攻击、弹道、贯穿、溅射与连锁都遵守画面上的紧凑攻击椭圆。
- 动态路线预警升级为发光轨迹、流动实心箭头与拖尾粒子，只在敌人到来前显示。
- 基地核心改用独立可替换水晶素材，并在资产清单记录来源、许可与替换提示。
- 新角色入场比例缩小，通关门改为紧凑尖顶裂隙门；暂停菜单增加返回主菜单并可切换模式。
