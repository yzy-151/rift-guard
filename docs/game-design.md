## 一局循环

master，目标是约 10 分钟完成“开场对话 → 组队 → 防守 → 节点三选一 → 分支事件 → 精英战 → 结局”，先证明队伍组合与移动值得操作。

- 3 名角色：近战防守者、远程火系输出、水系支援，使用原创代号占位
- 1 张横向战场：基地在左侧，敌人从右侧推进，战场含三条宽松通道
- 左侧约 40% 为可部署与移动区；点击角色或 1/2/3 选择，右键指定区域内目标点
- 自动攻击范围内敌人；默认优先攻击最接近基地者；移动时普通攻击暂停
- 空格战术暂停，Esc 菜单；Q 施放当前角色主动技能，冷却与范围可见
- 7 个节点：4 个普通战斗、1 个剧情事件、1 个精英战、1 个 Boss
- 非终局节点结束均进行一次三选一；最终 Boss 后直接进入结局
- 基地生命归零失败；角色倒地本节点不可用，节点结束半血恢复
- 单局等级与强化结算后重置；首版永久进度仅记录剧情解锁和设置

## 战斗和成长规则

| 类别 | 首版规则 |
|---|---|
| 基础属性 | HP、攻击、防御、攻速、射程、移速、暴击率、暴击倍率、元素 |
| 攻击形态 | 近战单体、远程弹体、范围伤害；与元素类型分别配置 |
| 普通伤害 | 攻击 × 技能倍率 × 100/(100+非负防御) × 暴击倍率 |
| 攻速 | 以每秒攻击次数表达；攻速加成统一为加法，首版上限 3 次/秒 |
| 成长 | 团队经验共享，角色各自记录等级；不做抢尾刀经验 |
| 等级初值 | 1—5 级，每级基础 HP 与攻击增加 8%，之后再试玩调整 |
| 元素 | 首版火、水、雷；不复刻原作完整规则 |
| 元素附着 | 每目标一个元素槽，持续 3 秒；同元素刷新时间 |
| 火 + 水 | 蒸发：本次直接伤害 ×1.5 |
| 水 + 雷 | 感电：额外伤害传递给最多 2 个近邻目标 |
| 火 + 雷 | 过载：小范围爆炸和短击退 |
| 反应约束 | 消耗附着；同目标反应间隔 0.5 秒；反应伤害不再次触发反应 |

master，近战阻挡、主动技能和走位共同构成操作价值，首版采用简化通道阻挡与局部避让，避免先引入完整动态寻路。

## 三选一强化

master，首版准备 18 张强化：输出、技能变化、元素联动、防守恢复各有覆盖，优先制造攻击方式变化。

- 示例：穿透弹（弹体穿透 +1）、火花链（感电跳跃 +1）、壁垒（防守者阻挡 +1）、急救（基地回复）、战术转移（移动后短时增益）
- 同次三张不重复；过滤未带角色、未解锁元素、满级强化与互斥强化
- 使用单局随机种子与独立奖励随机流；战斗随机不改变奖励抽样
- 池不足时由可重复的通用恢复/属性奖励补齐，卡片 ID 仍须互异
- 确认后只生效一次，禁用重复点击；弹窗期间敌人、弹体、冷却暂停
- 卡面包含对象、具体数值、当前层数和变化预览

## UI 与手感

master，视觉方向是深灰底、奶白文字、暗红主色和少量元素色，对话使用粗描边、平涂、大色块与夸张表情。

- 顶部：基地生命、节点进度、剩余敌人；底部：三角色状态与技能
- 选中角色才展示完整射程和移动边界，避免三圈叠加遮挡敌人
- 攻击表现：短蓄力 → 命中瞬间闪白/火花/音效 → 快速回位
- 普攻不全屏震动、不全局顿帧；精英破防与 Boss 终结才给强反馈
- 多次命中特效合并并设置粒子和音效并发上限；UI 不随相机震动
- 屏幕震动与闪光可降低，元素同时用图标/文字区分
- 设计基准 1920×1080，验证 1280×720、1920×1080、2560×1440
- 对话可快进、历史回看、自动播放；每段控制在 20—40 秒，战斗中不强制长对话

## 模块边界

master，RunDirector 管节点和种子，CombatWorld 管单位和伤害，RewardSystem 管强化抽样，DialogueRunner 管剧情图，AssetCatalog 负责角色 ID 到素材的映射。

master，表现层只订阅命中、死亡、血量变化等事件，伤害不能依赖动画播完才结算，避免加速和跳过动画改变战斗结果。

master，存档先支持节点之间继续，写入版本号、队伍、强化、剧情变量和随机状态；损坏存档给出可理解的恢复入口。

## 分阶段交付与验收

| 阶段 | 可交付结果 | 验收 |
|---|---|---|
| M1 | 1 角色 + 1 敌人 + 基地的灰盒防守 | 有限移动、射程、攻速、胜负和重开都能操作 |
| M2 | 3 角色 + 4 普通敌人 + 元素系统 | 调换队伍/站位可改变结果；反应无无限递归 |
| M3 | 节点、18 强化、等级、固定种子 | 三选一不重复、不无效、不重复领取 |
| M4 | 开场/事件/结局与旧表格导入 | 所有分支可到达终点；弹窗不穿透操作 |
| M5 | 3 套 Q 版动作、大立绘、UI、SFX | 动作命中时刻准确、轮廓清晰、图像无明显白/绿边 |
| M6 | Windows 测试包与录制场景 | 无需编辑器可运行，连续完成 3 局，存读档一致 |

master，性能目标为 60 FPS，先用 100 敌人 + 200 弹体压力场景实测并记录硬件与帧时间，再决定是否需要空间索引和对象池优化。
