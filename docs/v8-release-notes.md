# Mode 1 V8 — mission select and persistent records

- F4 opens a Helltaker-styled mission screen for the three current maps.
- Stage 2 and Stage 3 unlock only after clearing the previous mission.
- Cleared stages can be replayed with any unlocked three-character squad.
- Each mission card records best base health, best kill count, and best kill streak in the persistent compendium save.
- Mission background, frame, title, cards, and the F4 button can be replaced or repositioned through Excel.

Validation screenshots are generated in `docs/v8-validation` by the `--v8-test` run.
