# Mode 1 V5 — Helltaker presentation and Traveler skills

- Every game surface now uses the embedded Helltaker UI frame, button, background, transition, font, and UI sound assets.
- Story scenes use full-screen Helltaker backgrounds, opposing portraits, slide-in entrances, typewriter text, transition frames, and matching dialogue sounds.
- Traveler has seven active skill states: physical sword wave plus Anemo tornado, Electro chain lightning, Pyro burst, Hydro healing field, Geo destructible construct, and Cryo slowing field.
- Press `Q` or the Traveler skill button, aim inside the battlefield, then left-click to cast. The HUD shows the active element, skill name, and cooldown.
- Geo constructs block the route and can be destroyed by enemies. Elemental fields and tornadoes persist on the battlefield.

Validation screenshots are written to `docs/v5-validation` by the `--v5-test` QA run.
