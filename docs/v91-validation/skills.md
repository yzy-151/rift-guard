# V91 战斗机制与无尽战场

本轮保留 V86 的角色 ID、技能 kind、卡牌图标、元素关系、角色解锁、逐个部署和觉醒。现有可用角色共十位，含旅行者；未开放的四名角色没有借此次更新解锁。Q 为主动技能，E 为终结技。

普通攻击共有六类实际投递机制：延迟近战扇区、追踪弹、锁落点抛物弹、定向贯穿弹、分叉扇形弹、往返弹。直线弹与往返弹逐段检测真实碰撞，地形可以挡住；移动敌人能躲开定向攻击。原追加弹道、暴击、连锁、溅射、回声、元素和觉醒继续通过共同命中流程结算。

瞄准预览、释放反馈和持续区域共用 `ability_preview_geometry()` / `is_in_skill_geometry()`。线、扇、十字、平行带等形状在蓄力时锁定，不会因施法者移动而暗改落点。圆与环在无尽仍沿用原椭圆投影及地面锚点。各类技能的命中时序、弹道与召唤物规则仍独立存在。

## 地面路线与怪物

修复了生成点替换路线首点、而地图仍绘制旧首点造成的偏移。地面单位与绘制共用 `stage_route()`，出怪错位限制在首段路线上；普通前进不会寻找离开道路的捷径。受击位移、冲锋和落地后先回到刚才的路线段，再继续前进，召唤物继承路线和进度。飞行单位仍可直飞，蝙蝠保留攻击后撤离。

普通地面近战接敌时各自保留稳定攻击位置：与英雄中心约 60–79 个世界单位，丘丘暴徒为 96；前排位置占满后，后续怪物在外圈等候。移动到位后才进行接触攻击，走出蓄力落点仍可躲避。冲锋/跳跃落地后重新建立身体间距，脱战再回道路；角色和怪物不会为了分离而被每帧瞬移推开。

- 野猪骑士：0.72 秒锁向蓄力，随后进行有明确路径的冲锋。侧移可躲，墙体挡停，冻结暂停蓄力，结束后归路。
- 丘丘暴徒：0.9 秒攻击准备后旋斧 1.8 秒，每 0.55 秒结算接触伤害，七秒冷却。按用户要求只使用原攻击动作帧，不附加范围光圈、刀光、斧头或碎片。
- 保留源石虫死亡预警、自爆、地下僵尸、萨满治疗、复活盾兵与三个首领的独立机制。

## 三种无尽战场

| 地图 ID | 名称 | 实际地形 |
| --- | --- | --- |
| `blood_gate` | 血门回廊 | 原四方血门、环墙、可破坏通道与高台 |
| `frost_isles` | 霜汐群岛 | 六块错落冰岛与两处减速浅滩，保留宽阔穿行走廊 |
| `wind_cross` | 风蚀交叉庭 | 四段交错断墙与四角攻击高台，要求转移站位 |

选择面板的小地图从实际地形生成。选择保留到重新开始和构筑继承；旧数据无地图字段时沿用当前默认选择。无尽仍采用原移动追击玩法、首领阶段与成长倍率，不增加独立模式。

首领到来前十五秒预告下一阶段，前八秒暂停增援，并为存活已上场角色恢复 12% 生命和 15 能量；每阶段只发放一次。存量敌人仍会攻击。敌人总量、低阶杂兵和弹道沿用原性能上限。

保留首个 120 秒生存契约，后续循环提供击杀、生存、元素反应、首领击杀、精英狩猎和十二秒据点驻留。精英池尚未开放时改发击杀任务；阵容失去反应能力时，反应任务改为清剿。任务均可选，奖励只恢复有限生命/能量，不无限增加永久属性。
