# Rift Guard 恢复后的开发计划

更新时间：2026-09-08

## 已完成基线

- Godot 4.4.1 项目已经形成可运行的“模式一：裂隙守望”。
- 三关流程、最多三人小队、八名可选角色、元素反应、角色技能、怪物职业、Boss 多阶段、剧情对话、卡牌构筑、角色与卡牌图鉴、Excel 内容导入、音效与特效替换目录已经接入。
- V10 Windows 发布包：`builds/mode1-v10/RiftGuard-Mode1-V10.exe`。
- V10 提交：`18bf2d5`、`2c1fa8b`、`5328696`。

## 正在完成的 V11 批次

1. 选卡节流：击杀经验仍然驱动升级，升级奖励可排队；每次选卡后至少战斗 14 秒再弹下一次，避免连续打断。
2. 明日方舟式路线：每张图至少上、中、下三条折线路径，入口可来自上、右、下边缘，路线在基地前汇合。
3. 初期节奏：全角色基础移动速度下调，重新校准首关怪物生命、伤害、漏怪惩罚和经验曲线。
4. 关卡衔接演出：胜利剧情结束后右侧开门，新角色出场，旅行者走近完成解锁，两人进入门后加载下一关。
5. UI 成熟化：更小字号、图标化按钮、左上角强化图标与等级、底部头像/生命条/数值、暂停页完整展示本关构筑与角色面板。
6. 图鉴图标：角色、卡牌、技能和敌人先接入 CC0 临时图标，保留统一替换入口。

## 紧接着完成的 V12 批次

1. 无尽生存模式：约四屏的大地图，取消基地与固定波次，敌人从四周边缘生成并追击旅行者。
2. 难度随生存时间持续增长，怪物数量、种类、生命和伤害逐步上升。
3. 旅行者独立升级并无限抽卡，后期经验需求采用缓增长曲线。
4. 卡牌召唤的同行者跟随旅行者，移动中自动攻击；强化仍只针对当前在场角色。
5. 无尽模式 HUD、暂停构筑页、记录与入口独立显示。

## 验收与发布

- 一次性运行脚本解析、内容配置、战斗逻辑、关卡平衡、无尽成长和 GUI 测试。
- 视觉审核多路线战场、暂停页、关卡开门演出、无尽地图、图鉴与战斗 HUD。
- 修复验收问题后导出新的 Windows 发布包，记录 SHA256、版本说明和临时素材清单。

## 临时素材位置

- UI 图标：`game/assets/ui/icons/temporary/nieobie/`
- 特效包：`game/assets/vfx/third_party/`
- Helltaker 参考与素材流：`docs/helltaker-reference-workflow.md`
- 可替换内容表：`content/game_config.xlsx`

## 当前原则

- 模式一保留为首个正式模式；关卡 Buff 进入下一关自动清零且没有叠加上限。
- 素材路径、图标、立绘、特效、音效、对话和数值全部保持数据化或集中映射，方便后续替换。
- 先成批完成功能，再统一测试、视觉审核和发布。
