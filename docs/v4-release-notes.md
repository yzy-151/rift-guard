# 模式一 V4 验收说明

## 直接运行

- 公开配置版：`builds/mode1-v4/RiftGuard-Mode1-V4.exe`
- 本地参考版：`builds/mode1-v4-local-reference/RiftGuard-Mode1-V4-Local-Helltaker.exe`
- 两个版本旁边的 `content/game_config.xlsx` 都可以直接编辑；关闭游戏、保存 Excel、重新启动即可生效。
- 本地参考版的 Excel 已指向同目录 `content/images` 中的解包背景和按钮。

## 本轮可验收内容

- 旅行者初始无元素，首次升级三选一保证出现元素卡；选定后 HUD、人物光环、元素字样和攻击颜色同步改变。
- 116 张卡牌可重复叠加；机制卡包含额外弹道、扇形散射、贯穿、连锁、爆炸、追击、处决、击杀爆炸、巨物猎杀、战意成长、两名增援和四种场外支援。
- 关卡持续 345 秒，约 199 名敌人分三路出现；普通、疾行、重甲、飞行、远程、增益、护盾与 Boss 均有独立外观和行为。
- HUD 左上显示最近五项强化及等级，右上显示场外支援层数和下次触发时间。
- F2 打开永久图鉴；角色解锁、卡牌发现、敌人遭遇与关卡通关会跨重启保存。
- 第一关通关会自动进入第二关并让角色02入队，第二关通关解锁角色03；每关强化在重开与进入下一关时清空。

## 操作

- `Enter` 开始或重开。
- `1 / 2 / 3` 选择角色或奖励卡。
- 鼠标左键点角色，鼠标右键移动。
- `Space` 或 `Esc` 暂停，`R` 重开，`F2` 打开图鉴。
- `F6` 打开对话预览，`F7` 打开特效预览。
