# 后续开发计划

## V13：战斗深度与地图规则

1. 增加可部署格、不可部署格、高台、低地、阻挡物和捷径开关，让路线由地图结构产生。
2. 增加波次预览条、敌人类型预告和入口警报音，使动态路线预警更易读。
3. 为三张地图制作独立地形主题、路线机关和 Boss 场地变化。
4. 增加远程、飞行、护盾、增益、治疗、分裂、冲锋敌人的独立轮廓与受击反馈。

## V14：卡牌构筑与角色技能

1. 扩充八名角色的专属普通、稀有、史诗、传奇卡，并继续保持无限叠加。
2. 增加弹道分裂、折射、环射、追踪、回旋、地雷、场外支援和元素连锁等可见攻击方式。
3. 完成旅行者六元素主动技能的独立操作、冷却和图标反馈。
4. 增加构筑标签与卡牌联动提示，让五分钟后期形成大量敌人与多弹道清屏。

## V15：内容与视觉素材工作流

1. 建立角色立绘、Q版战斗帧、技能图标、敌人帧、特效和 UI 的统一导入清单。
2. 用占位素材文件名保持接口稳定，再逐项替换为最终素材。
3. 为对话加入 Helltaker 式切入、抖动、遮罩、文字节奏和音效时间轴。
4. 为 Excel 增加资源存在性检查与游戏内错误定位，填写错误时直接指出表名、行号和字段。

## V16：完整试玩与发布

1. 完成三关剧情模式和无尽模式的难度曲线、掉落经验、Boss 节点与结算。
2. 完成存档槽、设置、键位、窗口模式、音量、低特效和性能档位。
3. 做 30 分钟稳定性测试、低帧率测试、不同分辨率测试和 Windows 发布包冒烟测试。
4. 整理 GitHub README、素材替换说明、操作说明、B站录屏脚本和演示构筑。
