# Rift Guard V62

V62 完成三选一增益卡视觉重构，并收紧角色内容完成度规则。

## 主要变化

- 三选一增益卡改用五套品质框和对应组件，全部素材保持原始宽高比。
- 卡片内部重新留出安全边距，调整编号、品质、图标、标题、效果、说明和操作区位置。
- 降低默认亮度与饱和度，悬停时播放提示音并进行清晰高亮。
- 奖励页标题区仅显示水晶等级和幸运值，消除文字重叠。
- 仅开放具有正式立绘与动作素材的七名角色；六名占位角色在新旧存档中均保持未解锁。
- README 重构为当前版本界面、角色、战斗、地图和怪物展示。

## 验收

- 奖励页专项视觉验收：9 / 9 通过。
- Windows x86_64 发布规格：1920×1080。
