# V102 · 关卡与暂停导航修复

基于 V101，补回暂停菜单中的编队、关卡鼠标入口，保留设置、重开、图鉴、路线和主菜单；键盘 Tab 遍历全部八个按钮。

关卡与编队的 Esc、返回按钮使用相同的来源层级：暂停打开后取消回到当前暂停，主菜单打开后返回主菜单，无尽编队取消回到无尽地图选择。预览另一模式的关卡不会修改当前战斗模式，确认编队后才切换。

Windows：解压 ZIP，保持 `RiftGuard-V102.exe` 和 `RiftGuard-V102.pck` 同目录，直接启动 EXE；不需要安装 Godot。

专项覆盖普通关卡锁定/解锁与切换、三张无尽地图、卡牌选择、部署移动、主动技能、终结技、暂停各入口与状态刷新；另回归剧情、新角色迎接、通关/失败结束、工坊、战斗与特效。详见 `docs/v102-validation/README.md`。
