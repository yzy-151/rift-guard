# Rift Guard UI Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build a Godot editor UI laboratory that lets master visually move, resize, and replace UI assets while the game and Codex share validated Profile resources.

**Architecture:** Runtime panels consume semantic fields from `ui_layout_profile.tres` and `ui_skin_profile.tres`; an editor-only plugin reflects those fields into draggable preview handles. Writes are validated, protected by disk hashes, saved transactionally, and excluded from exports.

**Tech Stack:** Godot 4.4 GDScript `@tool`, `EditorPlugin`, typed Resource profiles, editor screenshots, headless Godot QA.
