# V88 素材规范与无尽后期负载优化实施计划

目标：在保留现有玩法和素材源文件的前提下，减小实际发布包、降低大批丘丘暴徒的运行负载，导出并发布 V88。

- [x] 记录当前导出 EXE、素材目录/图集尺寸、同场景 CPU 与绘制基线。
- [x] 建立可重复执行的素材导入规范：动画图集保持网格和透明通道，静态大图分级限制尺寸，剔除编辑器/测试/源稿导出。
- [x] 按实测选择有损导入压缩与静态图分辨率；保存原始 PNG，不直接压坏原稿。
- [x] 缓存未变化目标的导航场，给静态障碍建立空间索引；不降低命中、技能判定和怪物等级。
- [x] 验证路径查询等价、地图可达、重型怪压力场景及关键动画，复测实际渲染并记录限制。
- [ ] 导出 V88、检查发布包运行与资源完整性，生成 SHA256 和发布说明，上传现有 GitHub Release。

技术依据：Godot 4.4 官方图片导入文档区分 Lossy（文件大小）与 VRAM Compressed（显存）；不能把磁盘压缩率当作显存或帧率收益。
