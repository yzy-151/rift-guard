# V31–V32 战役事件与队伍共鸣实验计划

## 目标

V31 把路线图中的商店、休整、招募和隐藏节点从占位行为升级为可点击、可结算、跨关卡保留的战役事件。V32 增加数据驱动的三人队伍共鸣，使编队、角色关系和元素组合直接改变战斗构筑。

## V31：战役节点闭环

- [x] 新增裂隙币、战役增益、节点奖励记录与跨关卡保存字段。
- [x] 通关按击杀、基地剩余生命与 Boss 关奖励裂隙币，且同一关不会重复结算。
- [x] 新增 `campaign_node_resolver.gd`，生成商店、休整、招募、隐藏节点的三选一选项并执行价格/条件校验。
- [x] 新增 Helltaker 风格 `campaign_event_panel.gd`，支持鼠标真实点击、键盘 1/2/3、价格与结果反馈。
- [x] 商店可购买遗物或幸运；休整可选择壁垒、能量或补给；招募可改变三人编队；隐藏节点可解锁角色并获得特殊奖励。
- [x] 战役增益在下一关真实作用于基地、角色生命、起始能量和幸运。
- [x] 新增 V31 专项测试、视觉截图、发布说明、Windows 构建与 v31 GitHub 分支。

## V32：队伍共鸣系统

- [ ] 新增 `team_resonances.json`，提供至少十二套元素、角色羁绊和职业组合。
- [ ] 新增 `team_resonance.gd`，统一解析条件、说明与数值效果。
- [ ] 编队确认和关卡重置时重新计算共鸣，不依赖 UI 状态。
- [ ] 共鸣可影响攻击、生命、攻速、移速、反应伤害、起始能量、护盾和幸运。
- [ ] 战斗 HUD 与暂停战术中心显示当前共鸣及效果，构筑战报记录激活共鸣。
- [ ] 关系值达到门槛时解锁角色羁绊共鸣，元素三色与同元素组合互斥规则可验证。
- [ ] 新增 V32 专项测试、视觉截图、发布说明、Windows 构建与 v32 GitHub 分支。
