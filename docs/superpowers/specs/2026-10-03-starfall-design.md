# 裂隙守望 · 星夜守望 重构设计

基线：V86，fede2683391953d082300ef577f2967bb82fd6a9。用户授权重构玩法、地图、界面与表现，必须保留人物和怪物素材。原 V86 场景与内容保留，可从新版主菜单访问。

## 方向与取舍

参考视频的可读性、动感、可爱的战斗节奏，而非照搬其场景。采用月夜天文庭院：深蓝 #101a30、石蓝 #263953、星金 #efcf88、月白 #f1f2ee、薄荷 #81e0c5、莓红 #ef809b。原人物/敌人动画图集不修改。新增手绘场景背景，运行时程序绘制星屑、符文、预警与元素特效。

三个方案：仅换皮无法解决时序和交互；直接改动旧版大型模拟器风险很高；采用独立的新战斗场景并复用全部原始角色/敌人图集，保留旧入口。选择第三种，以完整且可验证的新游戏循环交付。

## 新版完整循环

标题与战绩 → 选择三人队伍和远征/无尽 → 自动普攻、主动走位、队友跟随与切人、Q 技能、E 终结技、Shift 闪避 → 收集星屑升级三选一 → 波次补给与增益构筑 → 三幕九波的远征或无限增长的无尽 → 胜负结算、战绩保存与重新开始。普通波次不强制中断战斗，在推进时恢复少量生命与月泉耐久；首领波次要求击败首领后才推进。

攻击具备蓄力/发射/飞行/碰撞/消失；敌人有近战挥击、冲锋、远程扇射、治疗支援、重甲和召唤，以及多阶段 Boss。预警为珊瑚红，玩家元素各自配色；蓄力过程中锁定目标，出手后不追踪修正落点。闪避有无敌时间和冷却。核心失守或队伍全灭导致失败。

## 工程边界

`game/starfall/` 独立存放数据、纯模拟、绘制、UI、入口与测试，旧脚本不耦合。`catalog.gd` 提供角色/敌人/构筑，`simulation.gd` 负责真实状态与事件，`arena.gd` 消费事件并绘制，`interface.gd` 提供菜单和HUD，`main.gd` 管输入/存档/音频/场景协调。场景节点与导出配置在 Godot 中可见。没有必须在线运行的服务。

## 验收

Godot 4.6 导入、静态解析及运行无错误；纯模拟测试覆盖弹道、闪避、技能冷却、升级选择、远征结算、无尽跨 Boss 波次、实体上限；真实渲染截图验证主菜单/编队/战斗/构筑/结算的布局；自动实战与手动输入检查；交付源工程、Windows 启动入口与操作说明。临时捕获与脚本放在用户指定缓存目录，正式交付放在此项目。
