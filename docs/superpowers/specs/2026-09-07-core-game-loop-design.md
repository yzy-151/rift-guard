# 裂隙守望：关卡制多角色塔防 Roguelike 核心设计

日期：2026-09-07  
状态：已获 master 方向确认，等待书面规格复核  
引擎：Godot 4.4.1

## 1. 产品目标

游戏采用明日方舟式路线防守与 Roguelike 局内构筑。玩家在一张 2.5D 斜俯视地图上部署最多三名角色，阻止敌人沿固定路线抵达水晶。不同敌人提供不同经验，水晶升级时暂停战斗并提供三张 Buff 卡三选一。单关持续五至七分钟，通关后清空本关 Buff，播放关间剧情，并按剧情进度解锁角色、卡牌、地图与图鉴条目。

首版可选角色总数为八名。旅行者是唯一初始角色，初始无元素。其余七名角色通过关卡与剧情逐步解锁。未确定具体角色身份的七个位置使用稳定角色 ID 与占位显示名，后续替换名称、数值、图片、动画和音频时不改战斗代码。

## 2. 游戏状态与进度边界

### 2.1 永久进度

永久存档保存：已通关关卡、已解锁角色、已解锁卡牌、角色图鉴、卡牌图鉴、地图图鉴、剧情阅读状态和设置。永久进度不会提高基础战斗数值，避免后期关卡必须依赖重复刷取。

### 2.2 关卡内进度

关卡内保存：三人编队、旅行者当前元素、水晶等级与经验、已选 Buff、Buff 层数、技能冷却、角色生命、岩造物、敌人状态和当前波次。胜利、失败或退出关卡时销毁全部关卡内 Buff。重新进入下一关时旅行者恢复无元素，必须在新关卡重新选择元素。

### 2.3 关卡状态机

关卡按以下状态运行：

`编队 → 关前剧情（如有）→ 部署准备 → 战斗 → 升级选卡 → 战斗 → Boss → 结算 → 关后剧情 → 解锁 → 下一关`

升级选卡会暂停模拟时间。关后剧情完成后才写入通关与解锁状态。失败不会播放成功剧情，也不会写入成功解锁。

## 3. 编队、部署与移动

每关最多部署三名已解锁角色。第一关只有旅行者，后续关卡允许从已解锁角色中编队。首版不引入部署费用，角色在关卡开始前或战斗中的安全阶段选择空格部署。

地图格分为地面格、高台格、通用格和禁用格。近战角色使用地面格，远程角色使用高台格或允许远程部署的通用格。角色部署后可以在所属战术格中心周围的小范围内移动，用于微调射程、避开范围攻击和调整阻挡位置；角色不能跨格自由移动。移动期间不能攻击或阻挡。

地面角色拥有阻挡数。地面敌人与角色接触且角色仍有阻挡容量时停止前进并攻击该角色。飞行敌人不受角色和岩造物阻挡。

## 4. 水晶经验与升级

水晶是唯一关卡经验容器。怪物死亡时直接向水晶提供经验，不使用可拾取经验球，避免怪海中遗漏奖励。

基础经验建议如下，最终值完全由数据表控制：

| 敌人类别 | 基础经验 |
|---|---:|
| 普通近战 | 8 |
| 快速敌人 | 7 |
| 重甲敌人 | 14 |
| 远程敌人 | 12 |
| 飞行敌人 | 11 |
| 增益敌人 | 18 |
| 护盾精英 | 24 |
| Boss | 100 |

升级阈值采用递增曲线，并根据关卡总怪物经验预算生成。标准五分半关卡目标为十二至十六次选卡。选卡期间敌人、投射物、计时器与技能冷却全部暂停。

连续击杀只增强声音、视觉和分数反馈，不增加经验，防止强势构筑进一步滚雪球。

## 5. 卡牌系统

### 5.1 卡池规模

首版目标为至少 100 张配置卡：

- 八名角色各八张专属卡，共 64 张；
- 六种旅行者元素赋予卡与十二张旅行者元素分支卡，共 18 张；
- 十二张全队、基地和生存卡；
- 至少六张元素反应与路线交互卡。

同一效果的不同稀有度必须使用不同卡牌 ID，便于图鉴、权重、解锁和数值独立配置。

### 5.2 抽取资格

抽卡前构建本次动态卡池，只有满足全部条件的卡可以进入：

1. 卡牌已由永久进度解锁；
2. 卡牌目标角色当前在场且存活状态不影响资格；
3. 卡牌所需元素或前置卡已经满足；
4. 卡牌未达到最大层数；
5. 卡牌不与本关已选卡互斥；
6. 卡牌符合当前关卡允许的稀有度与传奇上限。

卡池不足三张时加入通用数值卡作为保底。三张候选卡不允许重复 ID。

### 5.3 旅行者元素锁定

旅行者在本关尚未获得元素时，第一次水晶升级的三张候选中保证至少一张元素赋予卡。候选元素为风、雷、火、水、岩、冰。旅行者选择一种元素后立即锁定该元素，并从本关动态卡池移除另外五种元素赋予卡及其专属分支卡。元素锁定持续到本关结束。

### 5.4 稀有度

| 稀有度 | 基础权重 | 设计幅度 | 规则 |
|---|---:|---|---|
| 普通 | 60 | 10% 至 15% 数值提升 | 可多次叠加 |
| 稀有 | 28 | 20% 至 35% 提升或轻机制 | 有层数上限 |
| 史诗 | 10 | 改变攻击或技能形态 | 通常唯一 |
| 传奇 | 2 | 构筑核心机制 | 每关最多两张 |

权重在水晶达到指定等级后逐步提高高稀有度概率，但不会使用付费抽卡或局外货币。

## 6. 元素附着与反应

首版只实现风、雷、火、水、岩、冰，不加入草元素。火、水、雷、冰攻击可以给敌人附着元素。风与岩自身不保留为普通附着，而是与敌人现有的火、水、雷、冰附着发生反应。附着拥有强度、剩余时间、来源角色与内部附着冷却。

反应结果如下：

| 反应 | 触发 | 战斗结果 |
|---|---|---|
| 蒸发 | 火＋水 | 水触发火为 2.0 倍，火触发水为 1.5 倍 |
| 融化 | 火＋冰 | 火触发冰为 2.0 倍，冰触发火为 1.5 倍 |
| 超载 | 火＋雷 | 范围火伤与强击退 |
| 冻结 | 水＋冰 | 普通敌人停止移动和攻击；Boss 改为减速与削韧 |
| 感电 | 水＋雷 | 在附近带水或可传导目标间跳跃 |
| 超导 | 雷＋冰 | 范围冰伤并降低物理防御 |
| 扩散 | 风＋火水雷冰 | 传播现有附着并造成对应元素范围伤害 |
| 结晶 | 岩＋火水雷冰 | 生成对应元素护盾，由触发者队伍自动拾取 |

增幅反应使用触发攻击伤害乘区。剧变反应使用触发者等级、元素精通、反应倍率和敌人抗性。首版实现简化元素量：每次有效附着增加一点元素量，反应消耗一点，元素量随时间衰减。该模型保留升级到更精确附着量系统的接口。

同一攻击的元素附着与反应拥有独立冷却，攻击可以命中但不一定每次重新附着。反应归属触发第二元素的角色。

## 7. 旅行者能力

### 7.1 无元素

无元素旅行者使用单体剑击与通用物理卡，保证元素卡出现前也能正常作战。

### 7.2 岩元素

选择岩元素后，选中旅行者时显示“放置岩造物”按钮。点击按钮进入落点模式，只能在旅行者技能范围内的合法地面格放置。

岩造物具有生命、护甲、持续时间、占格尺寸、阻挡数和技能冷却。地面敌人遇到岩造物时停止并攻击，飞行敌人忽略。Boss 对岩造物造成额外破坏伤害。地图必须保证即使岩造物放置在路线中央，也不会造成敌人永久寻路失败；敌人优先攻击造物，造物摧毁后继续原路线。

### 7.3 风元素

选择风元素后，选中旅行者时显示“龙卷风”按钮。点击按钮后选择目标方向，龙卷风沿直线移动，周期造成风伤、触发扩散并推动轻型敌人。精英与 Boss 通过韧性减少位移，韧性耗尽前不会被卷起。龙卷风不改变飞行路线节点。

其他四种元素在首版先提供自动攻击转换与元素分支卡，主动技能在相应角色系统稳定后逐步加入。

## 8. 地图与路线

每张地图由独立关卡数据描述：地图 ID、背景与前景素材、2.5D 投影参数、部署格、路线、出生点、水晶目标点、波次、音乐、环境特效和掉落解锁。

每条路线由有序路径点组成。地面、飞行和 Boss 可以使用不同路线。敌人始终向下一个路径点移动，抵达水晶后按漏怪值扣除水晶生命。路线数据与地图图片完全分离，因此更换背景不影响寻路。

首版至少准备三种地图规则：

1. 三路汇合地图，用于基础阻挡和射程交叉；
2. 双层高台地图，用于飞行敌人与远程敌人；
3. 双入口 Boss 地图，用于岩造物、击退和分队防守。

## 9. 敌人系统

敌人能力由可组合标签构成，而不是为每个敌人写独立战斗逻辑。

| 类型 | 核心行为 |
|---|---|
| 普通近战 | 接触阻挡者后近战攻击 |
| 快速敌人 | 低生命、高移速、低漏怪容错 |
| 重甲敌人 | 高护甲、低移速，压迫物理队伍 |
| 飞行敌人 | 忽略地面阻挡，只受可对空攻击命中 |
| 远程敌人 | 进入射程后停止并选择角色或水晶攻击 |
| 增益敌人 | 周期强化附近怪物的攻速、移速、防御或恢复 |
| 护盾敌人 | 拥有独立护盾值与元素弱点 |
| Boss | 固定波次出现，拥有阶段、韧性、技能和召唤规则 |

敌人选择目标、移动、攻击、增益和受控状态由统一组件处理。Boss 只通过配置和少量独立技能脚本扩展。

## 10. 关卡节奏与数量预算

标准关卡时长目标为五分三十秒：

| 时间 | 内容 |
|---|---|
| 0:00–1:00 | 部署、普通怪、第一次元素选择 |
| 1:00–3:00 | 快速、远程、重甲与飞行敌人逐步加入 |
| 3:00–4:30 | 怪海阶段，增加并发数量与增益怪组合 |
| 4:30–5:30 | Boss 波与混合敌群 |

普通设备目标为稳定显示八十名活动敌人，压力上限为一百五十名简化单位。超过视觉预算时合并伤害数字、限制同类音效、降低远处粒子与更新频率，但不会减少实际敌人或伤害计算。

## 11. 打击感与可读性

近战重击使用 25 至 45 毫秒局部命中停顿，普通远程攻击不暂停全局。命中反馈由受击闪白、短位移、命中火花、伤害数字、音高变化和小幅镜头震动组合。Boss 破盾、传奇连锁和大型元素反应使用更高一级反馈。

所有震动、闪光与粒子遵循“减少动态效果”设置。怪海中同一时间只播放有限数量的高优先级音效，重复伤害数字在短时间窗内合并。元素反应必须显示颜色、文字与轮廓变化，不能只靠粒子辨认。

## 12. 图鉴与解锁

角色图鉴显示角色身份、元素、定位、基础属性、技能、已发现卡牌和素材预览。卡牌图鉴显示稀有度、效果、目标角色、前置条件、最大层数、是否已解锁和首次获得关卡。未解锁内容显示剪影与明确解锁条件，不展示剧情剧透。

永久解锁发生在关后剧情结束时。存档写入使用临时文件后原子替换，加载失败时保留旧存档并回退到默认配置。

## 13. 数据与素材替换边界

战斗代码只依赖稳定 ID，不直接依赖角色名或素材路径。数据模块如下：

- `characters`：角色属性、职业、元素、攻击、技能与素材键；
- `cards`：效果、稀有度、权重、目标、层数、条件与互斥；
- `reactions`：元素组合、倍率、控制、伤害与素材键；
- `enemies`：属性、经验、移动层、能力标签与素材键；
- `stages`：路线、部署格、波次、时长、Boss 与解锁；
- `story`：关前、关后对话和解锁事件；
- `codex`：图鉴内容与解锁条件；
- `asset_manifest`：角色、怪物、地图、UI、音频和特效的逻辑键到资源路径映射。

占位素材与正式素材使用相同逻辑键。替换素材时只修改 `asset_manifest` 或 Excel 对应路径。角色动画统一提供 `idle`、`move`、`attack`、`hurt`、`skill` 和 `down` 动作键；缺失动作时回退到 `idle`，不得阻断战斗。

## 14. 技术架构

采用确定性固定步长模拟核心与 Godot 表现层分离：

- `RunState` 管理关卡内状态与重置；
- `CombatSimulation` 管理固定步长战斗；
- `StageRuntime` 管理路线、波次、部署格和关卡时间；
- `ElementSystem` 管理附着、内部冷却与反应；
- `RewardSystem` 管理经验、升级、动态卡池和卡牌应用；
- `AbilitySystem` 管理主动技能、岩造物和龙卷风；
- `ProgressionService` 管理剧情、解锁、图鉴与存档；
- `AssetResolver` 根据素材键加载占位或正式资源；
- `BattleView`、`BattleHUD` 和特效节点只消费模拟事件，不修改战斗结果。

现有 `combat_simulation.gd`、`combat_catalog.gd` 和 `reward_book.gd` 中的写死数据迁移到上述模块。旧功能在迁移期间通过兼容适配器运行，待新路径通过验证后再删除适配器。

## 15. 错误处理

启动时验证所有数据 ID、交叉引用、路线、波次、卡池和素材键。致命数据错误阻止进入对应关卡并显示具体文件、表名和 ID。素材缺失使用显眼占位图并记录日志。卡池过滤后不足三张时使用通用保底卡。路线断裂、出生点缺失或目标点缺失属于致命关卡错误。

## 16. 验收标准

1. 第一关只包含无元素旅行者，并能在第一次升级时从六种元素中选择；
2. 旅行者选择元素后，本关不再出现其他元素赋予卡；
3. 每次抽卡只包含当前场上角色及符合条件的通用卡；
4. 怪物经验按类型正确累加到水晶，并在跨越多个阈值时逐次触发选卡；
5. 通关前不进入下一关剧情，剧情结束后才完成角色或卡牌解锁；
6. 进入下一关后全部 Buff、旅行者元素和临时战斗对象归零；
7. 八种元素反应组合按表生效，并正确记录触发者；
8. 岩造物只能合法放置、能够阻挡并能被怪物摧毁；
9. 龙卷风能扩散、击退轻型敌人，并受到精英与 Boss 韧性限制；
10. 地面、飞行、远程、增益、护盾和 Boss 敌人分别遵守其行为规则；
11. 标准关卡在正常游玩速度下持续至少五分钟；
12. 怪海压力场景能维持八十名活动敌人且战斗结果不受视觉降级影响；
13. 角色与卡牌图鉴能够解锁并跨重启保存；
14. 替换角色、怪物、地图、UI、音频或特效资源无需修改战斗代码。

## 17. 实施顺序

1. 数据层、验证器与素材映射；
2. 关卡状态机、水晶经验和 Buff 重置；
3. 八角色编队与动态卡池；
4. 六元素附着和八类反应；
5. 路线、部署格、阻挡与三张地图；
6. 六类普通敌人与 Boss 框架；
7. 岩造物与风龙卷风；
8. 剧情解锁、图鉴与存档；
9. 怪海性能与打击反馈；
10. Excel 配置入口、完整验证与试玩构建。

## 18. 规则依据

元素系统采用先附着、后触发、反应消耗附着与触发归属的结构，参考：

- https://genshin-impact.fandom.com/wiki/Elemental_Reaction
- https://genshin-impact.fandom.com/wiki/Elemental_Gauge_Theory
- https://www.hoyolab.com/article/18426628

本作只复现六元素战斗关系，并按塔防可读性与怪海性能简化元素量、内部冷却和 Boss 控制规则。
