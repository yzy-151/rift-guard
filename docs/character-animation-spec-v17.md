# V17 角色序列帧交付规范

## 结论

每个角色只提供呼吸、跑步、攻击、阵亡四套动画，能做出基础战斗，但离上线观感还差“受击”和“技能/施法”两套。首批每个角色请交付六套：`idle`、`run`、`attack`、`skill`、`hit`、`death`。角色移动、跟随、碰撞、转向和位移全部由游戏代码控制，动画画面里不要做角色整体位移。

## 推荐帧数与时长

| 动画 | 帧数 | 基准时长 | 循环 | 用途 |
|---|---:|---:|---|---|
| idle 呼吸 | 48 | 2.0 秒 | 是 | 待机、瞄准间隙 |
| run 跑步 | 48 | 2.0 秒素材周期，游戏内通常 1.0–1.35 秒播放 | 是 | 移动与跟随 |
| attack 普攻 | 24–36 | 0.65–1.0 秒 | 否 | 每种基本攻击 |
| skill 技能 | 36–60 | 1.0–1.8 秒 | 否 | 元素技能、召唤、爆发 |
| hit 受击 | 8–12 | 0.20–0.35 秒 | 否 | 重击反馈，轻伤只闪白 |
| death 阵亡 | 36–48 | 1.2–2.0 秒 | 否 | 倒地并停留末帧 |

全部按 24 fps 原始时间轴交付。48 帧呼吸很顺；48 帧跑步本身偏慢，CC会按移动速度以 1.0–2.0 倍播放，不要求重画。

## 攻速与动画同步

游戏可以直接调整帧播放速度，但不会简单地把整段动画无限加速。每套攻击动画需要标出三个时间点：`anticipation_start`（蓄力开始）、`release_frame`（弹丸/魔法离手）、`recovery_end`（后摇结束）。游戏把 `release_frame` 绑定到实际伤害事件：远程角色在这一帧生成箭矢或法术，近战角色在这一帧生成判定框与刀光，音效和镜头震动也在这一帧触发。

攻速为基准值的 0.65–1.8 倍时，CC会同比调整动画播放速度；超过这个范围时优先缩短后摇、增加弹道数或追加攻击，而不是把人物播成抽搐。角色被控制、阵亡或释放技能时，状态机会打断当前普攻；普通移动会在当前攻击完成后过渡到跑步，过渡采用 0.06–0.12 秒淡入或在相同脚部姿态帧切换。

## 每个角色需要提供的文件

每套动作请提供透明背景的连续 PNG 或规则 Sprite Sheet。推荐单帧画布 512×512，角色脚底锚点固定为 `(256, 448)`，角色始终位于同一位置、同一大小、面朝右侧三分之二视角，不要包含地面影子、弹丸、刀光、烟雾、UI 和镜头位移。向左由游戏水平翻转；以后若追求四方向移动，再补前后方向。

每个角色还需要以下静态素材：透明全身基准图、武器独立图层、头像、卡牌半身像、元素/技能图标、弹丸或法术核心图、颜色参考。静态素材足够让 CC 控制移动、UI、弹丸和大部分特效，但人物肢体动画仍需序列帧或由这些基准图生成的动作帧。

目录请按下列形式交付：

```text
characters/<character_id>/
  portrait.png
  avatar.png
  weapon.png
  projectile.png
  skill_icon.png
  idle/0001.png ... 0048.png
  run/0001.png ... 0048.png
  attack/0001.png ...
  skill/0001.png ...
  hit/0001.png ...
  death/0001.png ...
  animation.json
```

`animation.json` 至少填写：

```json
{
  "fps": 24,
  "facing": "right_3q",
  "anchor": [256, 448],
  "clips": {
    "idle": {"frames": 48, "loop": true},
    "run": {"frames": 48, "loop": true},
    "attack": {"frames": 30, "release_frame": 12, "recovery_end": 30},
    "skill": {"frames": 48, "release_frame": 22, "recovery_end": 48},
    "hit": {"frames": 10, "loop": false},
    "death": {"frames": 48, "loop": false}
  },
  "sockets": {"projectile": [356, 238], "weapon_hand": [321, 274]}
}
```

`projectile` 坐标是弹丸生成点，`weapon_hand` 是武器绑定点。每个角色第一次交付时先给一张合成预览和一套完整普攻，确认比例、锚点与释放帧后再批量制作其余动作。
