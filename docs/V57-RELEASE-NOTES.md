# Rift Guard V57

## 第一关地图

- 蒙德草地与网格严格限制在战斗区域，其他关卡继续使用原有黑红格子地图。
- 七天神像放大并下移，血条位置保持不变。
- 移除七天神像、高台、自动机关和木栅栏的不自然椭圆阴影。
- 移除暂时没有完整玩法支撑的浮空平台。
- 两座木栅栏统一为可破坏阻挡物，可阻挡角色与地面怪物。
- 灌木使用贴近可见区域的椭圆碰撞，透明边角不再阻挡移动。
- 沼泽继续减速，高台继续强化角色射程，自动机关继续在角色靠近后提供低频超远程支援。

## 战斗信息

- 移除敌人头顶“空”“远”等文字和无战斗意义的横线、翅膀等装饰。
- 保留护盾与增益标识，保证有效状态能够快速识别。

## 无尽模式性能与难度

- 总人口预算从前期 108 逐步提高到后期 140，并在高负载时主动压缩。
- 低阶怪预算从前期 42 逐步收缩到后期 24，后期转向更高质量敌人。
- 敌人生命、伤害、速度与经验奖励按存活时间和难度层级分开增长。
- 限制哥布林茅房和同时存活 Boss 数量，Boss 出场时会优先替换低阶填充怪。
- 屏外普通敌人降低 AI 更新频率，寻路、增益扫描和路径探测加入缓存。
- 屏外预警、技能区域、投射物和特效不再提交渲染，高负载时进一步合并次要表现。
