# Rift Guard V48

master，V48 正式完成八关地图七层拆分，补齐此前 V30 仅有路线和传送门数据、但缺少完整主题化表现的问题。

## 地图七层

1. 背景：八关分别绑定 Helltaker 素材包中的八张章节背景。
2. 气氛：每关使用独立雾密度、漂移色带和远景轮廓。
3. 地面：保留透视投影与缓存地砖，八关拥有独立地面、地砖和强调色。
4. 路线：常驻路线只保留低对比地面刻痕，动态箭头仍只在敌人抵达前出现。
5. 地形：高台、洼地、障碍、机关和可破坏捷径继续使用真实战斗数据。
6. 建筑：前哨、回廊、母巢、空桥、熔炉、钟楼、冰晶和蚀日分别拥有独立轮廓语言。
7. 前景：前景城墙、碎石、余烬和关卡编号在单位与特效之后绘制，强化 2.5D 遮挡关系。

## 性能

- 地面 220 块透视地砖继续按关卡缓存，不在每帧重建。
- 建筑主题使用少量程序化几何，没有增加新的大纹理依赖。
- 路线、传送门和关键预警继续服从 V30 的表现预算，低负载与高负载行为一致。

## 可替换入口

- 地图色板：`game/data/stage_visual_profile.tres`
- 主题定义与层级顺序：`game/scripts/stage_surface_renderer.gd`
- 关卡背景绑定与绘制：`game/scripts/battle_view.gd`
- 路线、地形和出生点：`game/data/v2/stages.json`
