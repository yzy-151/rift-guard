# Rift Guard V64

V64 将普通关卡地形机制统一到 11×20 网格，并完成战斗 HUD、角色差异和敌人数值的集中调整。

## 主要变化

- Q / E 与增益图标使用固定安全尺寸、等比例缩放和父区域裁切，不再溢出底部 HUD。
- 持续伤害、高台、洼地、攻击强化和阻挡素材逐格贴合 60×40 地砖，角色与怪物按同一格判定触发。
- 普通关卡敌人沿格子中心水平或垂直行进；大型近战怪与 Boss 攻击提高，所有敌人生命提高。
- 角色终极技能提高能量消耗与冷却，并增强角色初始定位、强制位移后的脱困处理。
- 设置界面保留低特效与保存返回，两项并排放入框体；图鉴暂时移除外围装饰框。
- 赤潮回廊移除无功能的紫色拱形装饰，普通关卡清理废弃云台、门与旧地形表现。
- 战斗顶部信息、场外支援、Q/E 指令和五列增益区重新排版。

## 验收

- V64 定向校验：29 / 29 通过。
- Windows x86_64 发布规格：1920×1080。
