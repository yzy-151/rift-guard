# Rift Guard V53 发布说明

V53 重做了战斗 HUD 的信息密度、Boss 演出、敌人编队与障碍寻路，并统一了剧情文本动效。

- 队伍卡的生命条与能量条强制使用紧凑尺寸，姓名、状态与数值完整收进卡框。
- Boss 血条改为更厚的红黑装饰框；Boss 入场加入场景染色、预警框、字体和音效演出。
- 三段横向敌情栏改为顶部中央小型敌情牌，只显示当前敌军与最近一波。
- 近战敌人保留攻击前摇但不再显示范围圈；丘丘弓箭手射程降至 235，箭矢沿抛物线飞抵真实落点。
- 刷怪编队限制弓箭手、萨满、哥布林茅房、皮卡超人、治疗与护盾单位的同屏数量，并打散连续同类刷新。
- 60 个以上敌人时，近距离命中与元素反应特效按空间合并，伤害计算不受影响。
- 普通关和无尽模式统一使用绕障导航；怪物接近未破坏门后会攻击门，破门后立即重算路径。
- 正文、数值和说明改用规整半粗系统字体，装饰字体仅保留给游戏名、关卡名与 Boss 标题。
- 剧情正文取消打字机，整段文字以轻微放大后回落的弹入动画出现，选项继续使用 Helltaker 风格独立描边框。

验收结果：V53 自动化与视觉验收 21 项通过，0 项失败。
