# V26 发布说明

V26 将 V25 的数据基础转化为更明确的局内决策。

- 九张地图各有独立战术契约，目标覆盖击杀、元素反应和生存时间。
- 契约奖励支持幸运、结晶盾、全队能量和全队治疗。
- 六名 Boss 的十八个阶段现在会轮换执行 31 个阶段招式槽位（29 个独立动作），包括不同兵种召唤、炮击、扇形爆发、拉拽、击退、沉默、吸血、回血、护盾和地形破坏。
- 圆形、直线、多线、矩形、十字、扇形、棋盘、螺旋与圆环预警均有匹配的伤害判定。
- 技能瞄准支持右键取消，取消不会误触移动指令。
- 暂停战术中心显示契约进度、视觉质量比例和被性能预算丢弃的生成数量。
- 角色素材扫描把可运行占位与最终素材分开统计，报告位于 `docs/asset-readiness-v26.md`。

验收命令：

```powershell
Godot_v4.4.1-stable_win64_console.exe --headless --path game -- --v26-test
```

当前自动验收为 51 项。图形截图入口已经加入测试，但当前后台 Windows 会话无法初始化 EGL；在正常桌面会话运行同一命令时，会生成 `docs/v26-validation/` 下的截图。
