# V29 发布说明

V29 聚焦战斗动画状态、命中同步和元素反馈。

- 十二名角色统一接入呼吸、移动、攻击、受击、主动技能、终结技和阵亡状态契约。
- 攻击动画时钟可由角色攻速缩放，朝向与脚底锚点保持独立。
- 动画状态机在配置的命中比例发出一次性命中标记，避免一段动作重复结算。
- 技能时间轴强制让伤害、VFX 与 SFX 使用同一命中时刻。
- 新增十五套数据驱动主题，覆盖六元素、八类元素反应与中性伤害。
- 战斗事件携带主题数据，命中时叠加对应色彩的冲击环与核心闪光。
- 部署预览保存合法性结果，并以绿/红落点提示玩家。

## 验收

    Godot_v4.4.1-stable_win64_console.exe --headless --path game -- --v29-test

V29 专项共 22 项，覆盖动画、时间轴、主题、表现导演与部署反馈。
