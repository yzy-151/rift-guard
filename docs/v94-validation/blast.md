# V94 源石虫爆炸范围验证

2026-10-04。修改仅涉及 `enemy_tactics.gd` 的源石虫爆炸参数及其闪光尺寸；没有改动通用技能几何、丘丘暴徒旋斧或卡牌 `death_burst`。

## 最终行为

- `BUG_BLAST_RADIUS = 80.0`，原参数为 `125.0`。所有正常死亡经 `apply_hit → EnemyTactics.on_death → pending_impacts → EnemyTactics.explode` 共用该常量。
- 普通关卡保持圆形：半径 125 → 80，缩小 36%，面积缩小 59.04%。
- 无尽模式保留原有椭圆投影及中心的 8 像素地面偏移：半轴 119.5 × 47.8 → 91.6 × 36.64，每个方向都缩小约 23.35%。这里的 80 是传给原有范围投影的半径参数，不把无尽模式改成半径 80 的圆形，以免扩大原来的纵向伤害范围。
- 延迟仍为 1 秒，伤害仍为死亡源石虫当前 `damage × 1.5`；无尽等级缩放后的伤害也保持该倍率。
- 预警从待结算伤害记录读取 `radius`，爆炸事件原样携带该值。闪光缩放由固定 `1.5` 改为 `1.5 × radius / 125`，本次为 `0.96`，保留原来的短促闪光与散落碎片。
- `volatile` 词缀的源石虫仍只触发一次延迟爆炸。通用词缀爆炸已有 `kind != "originium_bug"` 排除条件；源石虫目录项没有火史莱姆的 `death_burst` 字段。其他词缀、无尽缩放、卡牌连锁击杀均保留源石虫种类，死亡仍走同一路径。
