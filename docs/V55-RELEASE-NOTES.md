# Rift Guard V55

V55 重构战斗顶部 HUD，并修复第一章地图全屏铺设造成的角色、地形与背景层级异常。

- 顶部改为统一红黑状态条，完整显示等级、经验、元素、幸运、时间、基地、护盾、波次、击退数与当前状态。
- 移除巨型独立 Logo 和蓝色默认暂停按钮，改为紧凑品牌区与红黑暂停按钮。
- 战场恢复 `Rect2(16, 88, 1248, 490)` 的原有投影空间，角色脚底、地形和碰撞重新对齐。
- 蒙德背景与草地仅绘制在战场框内；接入 master 更新的无网格 `02_grass.png`。
- 网格改为运行时代码绘制，可独立调整透明度；草地降饱和并保留远景层次。
- 风神像核心缩小，避免遮挡角色和路线。
