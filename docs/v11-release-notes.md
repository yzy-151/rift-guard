# Rift Guard V11

## 新玩法

- 模式一的敌人改为上、中、下三条折线路线，入口来自地图上缘、右侧和下缘，并在基地前汇合。
- 选卡仍由击杀经验升级触发；升级奖励可以排队，每次选择后进入 14 秒战斗间隔，避免连续弹窗。
- 全角色早期移动速度下调，首关五分钟自动构筑模拟保持可通关。
- 关卡胜利剧情结束后播放右侧开门、新角色出场、旅行者会合并共同进入下一关的解锁演出。
- 新增“模式二：无尽生存”：四屏地图、四边刷怪、敌人追击旅行者、无固定波次、持续难度成长、旅行者无限升级抽卡。
- 无尽模式中的增援角色自动跟随旅行者，并可在移动中攻击。

## UI

- 顶部按钮、元素技能、角色与卡牌图鉴接入临时图标。
- 左上显示本局强化与等级；底部角色卡显示头像、生命条、生命数值和关键战斗属性。
- 暂停页显示本关全部强化等级及当前三名角色的 HP、攻击、攻速、射程、护甲、移速和弹道数。
- 无尽模式显示旅行者等级、经验、生存时间、威胁等级和旅行者生命。
