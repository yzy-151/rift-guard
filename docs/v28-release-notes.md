# V28 发布说明

V28 修复角色与怪物向左时立绘脱离世界位置和阴影的问题。

- 根因是 V27 使用负宽 `Rect2` 同时承担翻转和定位，Godot 绘制阶段对该矩形的处理与辅助测试采用的坐标假设不一致。
- 战场序列帧与单图素材现在始终使用正宽、正高目标矩形。
- 水平朝向通过围绕脚底原点的局部 `Transform2D` 镜像，外层世界位置与 2.5D 深度缩放保持不变。
- 旅行者、普通角色、丘丘人、史莱姆和备用敌人共用同一绘制入口。
- 芙宁娜改用 `AnimatedSprite2D.flip_h`，父节点缩放始终为正，并按翻转后的逐帧脚底锚点重新定位。
- 角色脚底统一为本地 Y=8，怪物脚底统一为本地 Y=12；阴影函数内部的 9 像素偏移已被抵消，因此静止基准帧的脚底与阴影椭圆中心重合。

## 验收

    Godot_v4.4.1-stable_win64_console.exe --headless --path game -- --v28-test

V28 专项包含 13 项检查，覆盖非对称透明帧、双向局部镜像、全部锚点目录、角色与怪物的脚底/阴影对齐、芙宁娜独立动画节点，以及负宽目标矩形清除。V27、V26、V25、V20 和 V17 回归共 226 项也必须通过。
