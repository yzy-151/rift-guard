# V18 角色序列帧交付规范

每名角色最低交付四段透明背景动作：待机循环、跑步循环、普通攻击、阵亡。待机和跑步建议两秒一循环，普通攻击与阵亡按动作本身决定时长；帧数不固定，优先保证首尾连贯、轮廓稳定、人物脚底不漂移。

技能动作可以先复用普通攻击，再由 Godot 叠加元素光环、冲击波和弹道。轻受击由程序对当前帧执行约 0.12 秒的横向拉伸、纵向压缩、闪白和回弹；重大受击可增加独立动作，当前不要求单独素材。

所有帧使用统一画布和固定脚底锚点，人物高度变化不得来自镜头缩放。攻击动画必须标注 `release_frame`，弹丸和刀光在该帧生成；游戏会按角色攻击间隔压缩或拉伸攻击动画的播放时长，因此更换攻速不会要求重新制作序列帧。

V18 当前旅行者规格为 288×288 单格、8 列、48 帧，脚底锚点为 `(144, 270)`，攻击释放帧为第 18 帧。怪物跑步规格为 256×256 单格、6 列、30 帧，脚底锚点为 `(128, 242)`。

绿色背景视频与透明 PNG 都可以交付。批处理入口为 `tools/build_v18_animation_assets.py`，输出到 `game/assets/characters/<角色>/`，运行时只读取图集与 `animation.json`，原始视频不进入发布包。
