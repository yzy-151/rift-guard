# Rift Guard V60

V60重构了模式选择、关卡选择、编队、角色详情、剧情交互、暂停页和战斗底栏，统一为不变形的红黑UI系统。

- 模式卡、设置按钮、远征检查点与继续远征按钮改为代码绘制的等比例面板。
- 选关页移除背景图，八张关卡缩略图改为真实战斗截图裁切，新增返回键与Helltaker选关音效。
- 编队页支持滚轮浏览全部角色，不再遮挡最后一排，并新增返回键、选中高亮与点击音效。
- 角色详情页在左侧播放breath序列，右侧展示六项初始属性条、Q战技、E终结技和确认选择。
- 剧情页删除“战场已暂停”和继续按钮，点击画面即可推进；右下角仅保留跳过、历史、自动三个图标，并使用booper0001—0028作为动态推进提示。
- 战斗顶部把地图名纳入状态栏，底部角色卡与Q/E框改成代码绘制面板；暂停页移除白色拉伸外框并对齐角色数值。
- 无尽模式删除T字裂谷、十字裂谷及对应阻挡墙，保留环形墙门、双向回廊、高台和血沼。
