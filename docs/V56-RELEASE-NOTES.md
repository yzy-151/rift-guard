# Rift Guard V56

V56 修复第一章素材错误扩散到后续关卡的问题，并完成第一关地形机制与视觉融合。

- 蒙德视觉仅用于 `stage_01`，第二、三关和后续关卡恢复原始暗色格子渲染。
- 草地改为不透明地面，运行时绘制清晰透视格子，背景压至远景层。
- 七天神像放大 1.6 倍，所有地形和单位阴影按脚底或底边重新接地。
- 新增第一关 CanvasItem 融合 Shader，统一饱和度、对比度、环境色和远景雾化。
- 两座木障碍都可被战技破坏，并阻挡角色与地面怪物。
- 沼泽减速 28%；高台增伤 22%、射程提高 38%。
- 移动平台使用独立占位素材，可承载角色移动并提供射程强化。
- 自动机关使用独立占位素材，角色靠近后每 5.5 秒进行一次 900 半径远程攻击。

定向验收：16/16，通过第一关机制、第一关截图、第二关原始风格、第三关回退和移动平台载人检查。
