# V27 发布说明

V27 聚焦带素材单位的朝向、锚点稳定性和召唤物表现。

- 修正丘丘人素材原生朝右但向左移动时未翻转的问题，怪物现在始终朝向移动方向。
- 新增统一脚底中心锚点，旅行者、芙宁娜、丘丘人和史莱姆反向时不再发生位置跳动。
- 从 master 提供的绿幕素材中抠出风、雷、水、火史莱姆与史莱姆王，并接入九种敌人职责。
- 史莱姆使用弹跳、落地压缩、攻击蓄力和受击拉伸，不依赖额外序列帧。
- 星轨剑阵改为竖向飞剑，数量按 2 / 3 / 6 柄成长，对应 180° / 120° / 60° 等间隔。
- 同一张剑阵卡升级时更新既有剑阵，不再叠加重复实例；9 级加入周期剑雨。
- 新增可重复执行的绿幕抠图与逐帧锚点生成工具。

## 验收

    Godot_v4.4.1-stable_win64_console.exe --headless --path game -- --v27-test

V27 专项包含 21 项自动检查，覆盖素材映射、透明素材规格、原生朝向、双向锚点和剑阵等级进化。
