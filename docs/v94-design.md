# V94：工坊工具栏与作战收尾

保留 V86 的红黑、粗线条界面与原有剧情、漫画和转场素材。工坊顶部使用扁平斜切色块，突出播放状态；单帧、倍率、恢复、清场、退出按用途分组，仍占用原来的 48 像素高度。

源石虫自爆半径由 125 缩至 80，预警、判定和碎片闪光使用同一半径。保留一秒引信、伤害和无尽模式原有投影，避免缩小水平范围却扩大纵向范围。

删除作战结束时自动打开的成就弹窗及旧胜利结算框。成就和通关奖励照常写入存档，成就可从图鉴查看。普通通关保留剧情、成功动作和转场，进入同行者到场与下一关编队；最终通关返回模式菜单；失败播放原有死亡动画，确认一次后返回模式菜单。

结果流程只允许进入一次；动画确认优先接收鼠标、Enter、空格和 Esc，其余战场输入在转场期间暂停。已看过或缺失的通关剧情也能继续，防止停留在隐藏的胜利状态。

验证以原生窗口输入和实际 Windows 发布包为准：工坊各控件、普通/最终通关、连续两次失败、无尽失败、成就保存、旧弹窗不再出现，以及自爆边界和可视范围。
