# V86 卡牌刷新与联动

- 每次选卡提供 2 次免费刷新，支持按钮与 R 键，尽量避开本轮已展示的卡牌，保留原有品质保底和元素限制。
- 新增 8 组卡牌联动：不灭之心、战斗狂热、火力交织、生命潮汐、双轨共振、天火坠落、术式超频、巨兽终结。
- 选卡页可查看联动图鉴、缺少的卡牌和同角色条件；联动每组只激活一次，重复卡仍按原效果叠加。
- 联动仅在获得卡牌时检查，战斗读取缓存结果，避免增加逐帧卡池扫描。
- 包含工作区此前的卡牌差异化、治疗特效、剧情、家园和关卡修复。

验证：60 组随机种子、刷新预算与保底、目标角色限制、8 组联动、实际伤害/治疗/范围、快照继承，以及 1280×720、1920×1080、2560×1440 界面检查。

Windows 64 位独立 EXE，资源已嵌入，无需单独 PCK。
