# V88 素材与无尽性能优化

## 实施
- 保留原始 PNG；用 `tools/normalize_texture_imports.py` 统一 242 张纹理的导入规则，可重复运行。
- 普通序列图使用质量 0.88 的有损存储，保持帧尺寸、透明度、锚点与 24 FPS 不变；不缩放整张序列图。
- 丘丘暴徒与大皮卡序列使用兼容 OpenGL 的 S3TC 显存压缩；大幅静态立绘/转场限制最长边 1536。
- 无尽导航按目标网格缓存，最多 12 个场；地形重建时失效；障碍物用 256 单位空间分桶。
- 48 个以上敌人的无尽场景减少重复等级文字与装饰，保留受损血条、护盾条、冻结标记；Boss 不降级，攻击预警仍独立绘制。
- 保留原有重型敌人透明区域裁剪，未改变怪物伤害、血量、数量与攻击判定。
- 新的额外剧情插图仍排除出包；本版包含现有无尽地图/任务三连抽、Boss 预警与视频帧动画，以及此前剧情和成就修复。

## 同场景对照
Godot 4.4.1 Compatibility，RTX 5060 Ti，种子 42，80 个高血量重型敌人，3 位高攻速角色，300 帧，60 帧预热；不是自然游玩帧率保证。

| 指标 | 优化前 | 优化后 |
|---|---:|---:|
| 逻辑耗时 p50 (ms) | 5.13 | 2.81 |
| 逻辑耗时 p95 (ms) | 10.77 | 4.66 |
| 整帧耗时 p50 (ms) | 28.36 | 23.79 |
| 整帧耗时 p95 (ms) | 36.33 | 28.95 |
| 绘制调用 | 1504.00 | 1364.00 |
| 纹理显存 (MiB) | 641.26 | 607.26 |
| 引擎静态内存 (MiB) | 238.27 | 238.77 |

同内容基线 EXE 为 422,260,080 字节（402.7 MiB），优化版约 297.3 MiB，减少 26.2%。内存并未显著下降，主要收益来自 CPU 重复计算减少、绘制简化、纹理显存与下载体积减少。极端堆叠 80 个重型敌人仍未达到 60 FPS，不把本次改善描述成完全消除卡顿。

## 验证
- 6000 次索引/全扫描碰撞对照通过；缓存导航与重新计算一致，地形重建失效正确。
- 无尽任务三连抽及实际鼠标点击、正常升级奖励独立、爆炸连锁、后期 Boss 成长通过。
- Boss 警报四次音效提示、双 Boss 动画逻辑、10 个角色关卡结束走路/朝向通过。
- 成就接收鼠标/键盘与续关测试通过；UI Lab 16 项通过。
- 10 分钟无尽模拟通过：4578 击败、峰值 96 个敌人、599.83 秒，逻辑 p95 39.65 ms（此长测包含其他验证并行运行时段，不用于前后帧率对照）。
- 导出包独立目录启动通过；强制结束时存在 ObjectDB/resource 释放警告，未观察到启动阶段资源缺失。

Godot 官方说明：[纹理导入及压缩](https://docs.godotengine.org/en/4.4/tutorials/assets_pipeline/importing_images.html)。有损存储主要减少文件体积；VRAM 压缩才会降低 GPU 纹理占用。
