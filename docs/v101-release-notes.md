# V101 · 工坊实验场景

基于正式 V100（18082a8）继续，新增可跨进程复用的工坊场景；保留 V100 的战斗、剧情、家园与素材。

## 使用

设置 → 示范工坊 → 选择三个场景槽之一 → 保存场景（F5）／载入场景（F9）。槽位摘要显示地图、在场角色、敌人和卡牌数；覆盖已有槽和载入替换当前工坊均需确认，可取消并恢复原来的运行／暂停状态。

保存地图与无尽布局、角色和敌人当前位置、按顺序施加的卡牌、自动普攻、敌人行动、无敌、无限能量和时间倍率。载入恢复满血实验起点，时间归零并暂停，可用空格运行或逐帧观察；不会继续旧弹道、已造成的伤害或技能计时。带构筑的隐藏角色也保留，防止遗漏共享卡牌效果。

场景独立保存在 Godot 用户数据目录的 `workshop_scenarios/`，三个槽各保留最新和上一次完整配置，不修改战役检查点或玩家进度。文件包含版本、槽号和目录 ID；损坏、未知版本、缺失角色／卡牌、不合法坐标均不能直接载入。若上一次配置仍完整，摘要和按钮明确提示“恢复备份”，确认后才替换当前工坊；没有可用备份时保持当前场景不变。

保存使用同目录临时文件刷新后提交到全新代文件，不覆盖已有文件，避免 Windows 替换失败丢失旧槽；成功后保留上一份有效配置。共享卡牌同时记录当时已存在和已部署的角色名册，后来加入的角色不会在重放时错误获得此前的共享加成。

## Windows 包

解压 `RiftGuard-V101-Windows.zip`，将 `RiftGuard-V101.exe` 与同名 `.pck` 保持在一起，运行 EXE；无需安装 Godot。源码构建使用 Godot 4.6 官方 Windows 发布模板与 `tools/build_v101.ps1`。

2026-11-03 验收包位于 `releases/V101-20261103/`；构建与验收记录绑定游戏源码/配置及实际 EXE/PCK 的 SHA256，打包前再次核对，拒绝将旧测试报告用于已变化的构建。旧本地 V101 包仍保留。
