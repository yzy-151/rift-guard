# V54 发布说明

V54 完成第一章蒙德城郊地图素材的首轮接入，并同步收紧战斗顶部 HUD。

## 地图

- stage_01、stage_02、stage_03 使用蒙德城郊 1920×1080 背景。
- 草地 32×18 网格按照素材说明，以 Y≈505 为远端接缝投射为 2.5D 梯形战场。
- 高台、泥沼洼地、不可通行灌木、破坏木障碍和风之机关分别映射到现有地形数据。
- 基地核心使用独立风神像素材，并保留生命、受击闪烁和碰撞逻辑。
- 第二章与无尽模式保持原有地图渲染。

## 顶部 HUD

- 使用 hud_logo.png 和 hud_topbar.png。
- 等级、经验、元素、幸运、时间、基地生命与护盾收进单行状态栏。
- 敌军预告缩成居中徽章，图鉴继续通过 F2 打开。

## 可替换位置

第一章全部地图图片位于 game/assets/world/chapter1_mondstadt/，Godot 绑定位于 game/data/stage_visual_profile.tres。
