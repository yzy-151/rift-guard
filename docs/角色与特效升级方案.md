# 角色与特效升级

master，结论是角色以骨骼动画为主、少数夸张动作补帧动画，特效采用现有序列帧。

## 实际素材检查
master，holopix/Co-myWn98awRph4DCILG7.png为2048×1152的RGB白底部件展示板，左侧是完整角色，右侧有头发、脸、眼睛、躯干、衣服、手臂、手掌、腿、鞋和王冠等部件。
master，它不是带透明通道、统一轴心和层级的现成骨骼工程，也不是连续动作帧，不能按格子直接当走路序列播放。
master，目前只有这张角色板，不能据此把三名不同角色都替换成各自完整的动作素材，本版未声称完成角色替换。

## 最合适的制作顺序
1. master，保留展示板原图，按部件分别抠图成透明PNG，白衣和皮肤内部白色必须保留，不能全局删白色。
2. master，把肘、膝、肩、颈、发根等被遮住的位置补齐，让转动时仍有重叠，避免出现裂缝。
3. master，统一画布与原点，以脚底接地点为角色原点，以髋部为动作根，记录每片尺寸、偏移和左右属性。
4. master，在Godot建立骨架：髋部→躯干→颈部→头部，躯干→上臂→前臂→手，髋部→大腿→小腿→脚，头部挂王冠及前后头发。
5. master，先做待机呼吸、移动重心、普通攻击、受击和倒地五种动作，用关键帧控制旋转和位移，眼睛/嘴巴换图。
6. master，普通动作复用骨架，转身、夸张挥击或大招用少量逐帧补间，攻击伤害仍由战斗模拟触发，不能依赖动画播完。
7. master，在游戏实际80至120像素显示高度检查轮廓与关节，再补侧视或斜侧视素材，目前正面部件无法自然覆盖所有转身角度。

master，Godot官方支持剪纸式部件动画与AnimatedSprite2D逐帧动画混用，具体方案采用两者组合：https://docs.godotengine.org/en/stable/tutorials/animation/cutout_animation.html
master，骨骼绑定参考：https://docs.godotengine.org/en/stable/tutorials/animation/2d_skeletons.html

## 建议的素材流水线
master，角色身份参考→多视图与部件生成→透明抠图→关节补画→部件与原点检查→Godot骨架绑定→动作预览→游戏内缩小验收→版本化导出。
master，每个角色最终保留原始图、透明部件、绑定工程、动作资源和素材清单，清单记录角色ID、部件名、轴心、来源模型/LoRA/种子及使用状态。
master，生成式AI适合补关节和生成关键姿势，连续帧仍需检查脸、手、服装和尺寸一致性，自动生成结果不应直接当作已验收动作。
