# V95 性能与静态地图验证

环境：Windows、Godot 4.6、Compatibility / OpenGL 3.3，AMD Ryzen 5 5600H，NVIDIA GeForce RTX 3050 Laptop GPU（546.30）。对照关闭 VSync，1920×1080 窗口。

## 固定场景

种子 9511，旅行者／洛琪希／格温，固定 1/60 秒逻辑步长。每场 140 帧，前 20 帧预热，余下 120 帧计时。分别为空场、14 丘丘暴徒拥堵、96 怪物无尽压力。双方高血量，避免怪物死亡减少数量。计时包含真实模拟、事件、图鉴、HUD、特效推进和 OpenGL 绘制。

这是一段可重复的短压力场景，不是完整关卡通关的平均帧率。报告帧耗时而非宣称固定 FPS。正式前后数据与发行包结果见本目录 JSON／发布验证记录。

## 地图缓存

原绘制每次重建路面多边形、墙体和地砖命令。现在使用一个保留绘制命令的 Node2D：移动镜头时平移，地图切换、道路几何、地形或门血量改变时重绘。水面、机关、功能地形和任务圈仍在实时通道。缓存键忽略 `clock` 和 `timer`，这些字段的逻辑更新不会让静态缓存失效。

无头回归覆盖地图切换、连续推进地形计时、镜头移动、墙体编辑触发一次失效和功能机关保留实时绘制。

原生截图将缓存开关前后冻结在相同时间，并逐像素比较所有八个战役场景与无尽场景：stage_01、stage_02、stage_06 完全一致；其他战役超过 8 色阶的差异最多 217 像素（约 0.011%），无尽没有超过 8 色阶的差异。地形几何与单位位置未改；少量细线覆盖存在像素差异。实际图像已经人工检查。详见 `performance/stage-pixel-comparison.json`。

缓存没有缩减敌人数或删除特效。低特效模式继续沿用原设置。

## 复验

源工程：`game/tests/qa_v95_stage_cache.gd` 可使用 `--headless`，或窗口模式输出缓存前后图像。绝对 `--qa-output` 必须指向临时目录以隔离存档。

发行包内置 `--v95-performance-test --qa-output=<绝对目录>`；使用相同固定场景，输出真实运行耗时、敌人数、画质档位和截图。
