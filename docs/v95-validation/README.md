## 性能对照

同机、同 Godot 4.6、1920×1080、相同种子和敌人数，独立进程顺序运行，无并发 Godot 或编码任务。每场固定 140 帧，前 20 帧预热。以下为源运行器载入 V94 发布 PCK 与 V95 源工程的对照；真实发布 EXE 的结果另记在发布报告。

| 场景 | V94 平均帧耗时 | V95 平均帧耗时 | V94 / V95 P95 |
| --- | ---: | ---: | ---: |
| 战役空场 | 11.89 ms | 8.08 ms | 14.05 / 10.92 ms |
| 战役 14 暴徒 | 16.50 ms | 10.82 ms | 23.31 / 12.29 ms |
| 无尽 96 混合敌人 | 55.73 ms | 28.33 ms | 88.18 / 46.28 ms |

96 敌人场景的逻辑均值为 39.57 → 13.29 ms，两边敌人均保持 96，末帧自动质量参数均为 0.58。保留原自动负载调整，没有手动减少敌人数来得到数据。压力场景仍有较慢帧，不能据此承诺所有电脑／完整关卡稳定 60 FPS。

主要修复为：共享队列排序、身体／预约位置近邻查询、障碍候选网格、避免重复移动碰撞、静态地图命令缓存以及相同单位阴影轮廓复用。碰撞仍使用原精确判定；动态水面、机关和技能照常推进。

## 发布包复测

`RiftGuard-V95.exe` 已通过 528 项检查：模拟 78、暂停 72、剧情 42、爆炸 129、结束流程 111、经典内容及打包资源 96。七个独立测试进程（含性能场景）全部退出码 0，无脚本／运行时错误。实际发布版的二选一和暂停截图见 `release/choices.png`、`release/pause.png`。

发布版同一 96 敌人压力场景：逻辑均值 10.24 ms，整帧均值 23.21 ms，P95 31.89 ms；普通 14 暴徒场景整帧均值 9.83 ms。该数据来自 release 模板，和上方相同编辑器运行器的 A/B 分开记录。

独立代码复核发现并修复两处边界：前后排共同侵入角色身位时的恢复死锁，以及无尽工坊手动目标误用追击角色流场。两处均先复现失败，再验证绕墙首次抵达、恢复攻击与正常队列不后退。
