# Rift Guard V46

master 的 V46 把八类玩家可见 UI 纳入 Godot 编辑器内“UI 实验台”：剧情、选模式、选关、选角色、普通战斗、无尽战斗、强化卡和设置。

master 可在每页实机参考截图上拖动和缩放语义框，也可在 Inspector 精调；选角色、强化卡和设置页运行时已改为读取两个 Profile。

master 可通过 ui_skin_profile.tres 替换背景、按钮、模式卡、关卡卡、选项框、强化卡和 Q/E 框体，完整字段对照包含在 DOCX 与 Markdown 图文手册。

V46 验证覆盖 V34 38/38、UI 完整点击流程 41/41、UI Lab 16/16，以及布局和贴图事务写回。
