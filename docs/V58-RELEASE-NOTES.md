# Rift Guard V58

## 无尽模式性能

- 屏外普通敌人以 5Hz 粗粒度更新位置和 AI，Boss 与当前屏幕敌人保持完整更新。
- 屏外战斗事件在进入视觉系统前丢弃，避免无效特效对象和动画状态堆积。
- 弹道通过敌人 ID 索引直接取得目标，取消逐弹道遍历全部敌人的开销。
- 增益扫描只处理当前屏幕邻近区域，Boss 腾位时同步维护敌人索引。
- 120 个以屏外为主的敌人专项基准为 7.28–9.90ms/帧，低于 V57 的约 20.52ms/帧。

## 无尽模式规则与控制

- 失败条件改为所有已上场角色全部阵亡，旅行者单独阵亡不会立刻结束。
- 旅行者、芙宁娜及其他队友均可单独点击后使用 WASD 或鼠标移动。
- 手动移动非旅行者角色后，该角色保持独立目标。
- 玩家选中并移动旅行者时，其他角色才重新进入延迟跟随队形。

## 角色差异

- 旅行者：剑气斩、近战格挡与范围劈砍。
- 少女与艾米莉亚：冰晶穿透、减速与冻结花。
- 希露菲：风种连锁与治疗强化。
- 芙宁娜、洛琪希：水泡回响与不同半径的溅射攻击。
- 知更鸟、丰川祥子、萨勒芬妮：音符多弹道、连锁或回响攻击。
- 阿米娅：高伤术式贯穿与暴击倾向。
- 风堇、凯尔希、铃：量子门多弹道、Mon3tr 重击和以太连锁。

## 战斗反馈

- 攻击与命中音量提高，并按攻击类型调整音高和重量。
- 弹道加入角色类型轮廓，命中特效加入扩散环、能量射线、第三方 flare、spark 和 trace 分层。
- 高密度战斗继续合并同区域次要特效，保证伤害计算完整。
