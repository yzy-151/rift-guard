# V93 验证与观看

V93 保留 V86 的界面、人物素材、剧情与元素构筑。本轮集中调整初始普攻与成长、循路行为、入场和攻击特效，并加入可以自行摆放单位的示范工坊。

## 查看

- `v93-workshop-combat.mp4`：25秒原生工坊录像，依次展示格温飞针、源石虫预警/闪爆、电极直线攻击、铁桶僵尸路线预警与入场。
- `gwen-needles.gif`、`impact-relay.gif`、`route-spawn.gif`：上述片段的GIF。
- [工坊操作和真实输入验证](workshop.md)
- [角色射程、卡牌上限与实际伤害](balance.md)
- [角色原作参考与本作改编](character-reference.md)

录像使用真实 CombatSimulation、BattleView、SheetEffects 与 BattleAudioDirector，固定24帧步进；不是画好的概念动画。飞针与爆炸段为清除地形的固定高血量靶场，电极段保留第二关真实地形，入场段使用第一关真实道路和缩短等待的三只铁桶僵尸波次。录像中工坊控制器由脚本操作；工坊按钮/键盘/地图坐标另有原生输入回归。

短闪爆取参考视频中的白亮内芯、迅速散开的细碎光和短余光节奏，自行实现，没有把原视频逐帧复制为素材。柔光复用已有 Kenney 资源与有上限的光效层。光效开启和低特效模式均验证。

修复过的边界包括：无卡固有范围攻击；高台目标可选却弹道飞不到；卡牌命中空中资格遗漏；弹道达到性能上限后访问空数组；拐角队列延长到路外或堵死；位移后斜向追人；休整期预警提前消失；同路同时两种来袭互相覆盖；通用几何抢占专属前摇；局部坐标把柔光画到左上角；工坊击杀误开选卡；暂停时重置残留特效。

原生画面与录像已在 Godot 4.6 / Windows / OpenGL Compatibility / RTX 3050 Laptop 环境检查。两个旧QA的退出阶段曾报告未释放的测试资源（HUD、旧角色技能脚本）；独立新回归和最终发布包结果另以发布报告记录。不能把通过检查等同于全部角色、八张地图及Boss长期平衡都已完成：数值报告只含受控伤害对照和60秒第一关实战抽样。

最终EXE/PCK测试结果、文件哈希和录像信息见 `release-report.json`。
