# V93 示范工坊

在主菜单或暂停战斗中按 **F10**，选择设置底部的「示范工坊」。工坊拥有独立的真实战斗模拟、地图渲染、技能特效和战斗音频；退出返回原来的设置界面，原关卡维持进入时的暂停状态。

## 操作

| 控件 | 用法 |
|---|---|
| 地图 | 8 张章节地图与 3 张无尽布局；切换地图会清空工坊摆放和构筑。 |
| 放置角色 | 选择名字，点击合法战场坐标。14 位目录角色可同时在场，不受正式三人编队限制；同名角色再次放置会重新摆放现有角色。 |
| 放置敌人 | 包含完整怪物与 Boss 战斗目录，可连续点击生成多只。 |
| 点击单位 | 选中并显示当前生命、攻击、护甲、普攻范围、攻速和移速；角色另显示能量。 |
| 右键 | 移动选中单位；正在放置或瞄准时取消操作。墙体和地图边缘不可放置。 |
| Q / E | 对当前选中的角色进入技能 / 终结技瞄准，再点击确定方向或落点。自中心技能沿用原规则。 |
| 卡牌 | 按原名搜索并添加，沿用原图标与效果。角色属性卡加给当前选中角色，支援、反应等队伍机制保留原共享作用域。旅行者元素卡须先选中旅行者。增援角色直接从角色目录放置。 |
| 重置全部构筑 | 去除工坊获得的所有卡牌，角色恢复初始构筑，保留角色与敌人的摆放。 |
| 自动普攻 / 敌人行动 | 分别控制普攻与敌人的移动、攻击、投射物和危害推进；关掉普攻仍可手动释放 Q / E。 |
| 角色无敌 | 直接阻止角色受伤，不消耗护盾。 |
| 无限能量 / 冷却 | 补满能量并清除 Q / E 冷却；关闭后沿用正式资源规则。 |
| 空格 / 逐帧 `.` | 暂停或继续；逐帧推进 1/60 秒，同时推进技能、渲染和特效。 |
| 速度 | 0.25、0.5、1、2 倍，使用工坊独立时间，不改变正式战斗或全局引擎时间倍率。 |
| 恢复 | 恢复在场单位生命、护盾和角色能量，清除角色冷却。已移除单位不会重新部署。 |
| 清除敌人 / 清空战场 | 分别移除敌人或全部在场单位，同时清除残留投射物与特效。空场不会判负。 |
| Tab | 收起 / 展开左侧工具抽屉，释放战场视野。 |
| WASD | 无尽地图平移视野；点击坐标经实际相机逆变换。 |
| Delete / Esc | 移除选中单位 / 退出工坊回到设置。 |

知更鸟、萨勒芬妮、凯尔希和铃沿用当前目录中的未完成内容，入口及属性面板均标注「未完成」。工坊可以检视已有素材与机制，但不会把这些角色解锁到正式进度。

## 隔离与实现

- `workshop_session.gd` 只持有内存状态，不引用存档、图鉴或成就服务。它创建独立 `CombatSimulation`，与正式场景共享战斗规则代码。
- 角色运行编号稳定；旅行者编号 0 保留，移除角色只撤下部署，不改变其他角色的技能归属。角色模板由正式初始化器产生。
- `workshop_mode` 禁止自动出波、胜负、奖励弹窗及契约推进。其余控制通过正式模拟中的明确开关实现。
- 主场景暂停并隐藏原来的场景节点，保留节点处理模式、可见性和音频暂停状态。退出停止工坊音频并释放整个工坊子树，恢复原设置及原战斗。

## 回归入口

`game/tests/qa_v93_workshop.gd` 使用真实根视口 `push_input` 驱动 F10、设置入口、角色与怪物放置按钮、战场点击、Q/E、卡牌添加、暂停、逐帧、地图下拉框、速度下拉框及退出。目录遍历时选择项索引用于覆盖准备，实际摆放和技能提交均走控制器输入。

命令：

```powershell
& 'C:/Users/yzy/Desktop/codex/tools/godot-4.6/Godot_v4.6-stable_win64_console.exe' --headless --path game --script res://tests/qa_v93_workshop.gd -- --qa-output=C:/Users/yzy/Desktop/codex/rift-guard/v93-2026-10-04/workshop/headless
```
