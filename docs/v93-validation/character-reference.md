## 本次实际修改

**格温 E「引针簇射」**：从三轮各五根改为一、三、五根，合计九根。每根有实体银白针身、尖端、封闭针眼、青绿拖线；针尖使用同一个模拟位置进行显示和扫线命中。开始施法和技能释放均不预扣目标生命。目标在针抵达前离开路径可以躲避，针沿通道贯穿，每根对同一敌人只结算一次。低特效模式保留针身、针眼和线，只减少柔光与碎片。Q「丝缕缠流」仍为本作的范围友军保护，并非原作圣霭对外部目标的不可选取规则。

**阿米娅 Q「精神爆发」 / E「奇美拉」**：黑色多面晶体有深色实心轮廓、紫粉裂边及碎晶尾迹；标记在目标头顶显示。奇美拉沿真正的狭长伤害区域生成黑晶裂隙、竖晶和三次脉冲，移除误示圆形攻击区的持续大圆。脉冲事件直接携带模拟判定几何。仍保留六枚追踪晶体、最多三层标记、终击消耗标记以及 8% 最大生命代价；雷元素类型和这些连携规则是本作适配，不是对原作真实伤害/技能代价的复制。

**芙宁娜 Q「孤心沙龙」 / E「万众狂欢」**：三个独立水形同伴有可区分的轮廓：卷尾海马、礼帽章鱼、双钳重甲蟹。小/中/重弹分别对应三者；发射后飞至落点才结算溅射，移动敌人可离开落点。舞台使用金色剧场弧、细水光与受益友军冠饰；累积的欢腾最多点亮五盏灯。此作没有加入芒荒切换或队伍扣血机制；区域治疗、攻击力缩放、12 秒时长和最高 45% 区域增伤均为改编。

**渲染入口修复**：旧的 `_draw_skill_zone` 先检查 `geometry`，所有有判定几何的 signature 区域因此被通用地面符号接管，实际飞针和沙龙成员无法进入自己的渲染器。V93 先处理 signature，再处理通用几何。蓄力描画也只处理 `_cast`，不在 `_impact` 后重复绘制静止假针。
