# V32 发布说明

V32 增加数据驱动的队伍共鸣系统，让三人编队、元素构成与角色关系直接改变实战数值。

- `team_resonances.json` 提供十四套共鸣，覆盖风、水、冰、雷、岩、三色、角色羁绊和支援职业组合。
- 同元素核心与三色棱镜按优先级互斥；其他角色羁绊可叠加。
- 共鸣可影响攻击、生命、攻速、移速、暴击、反应伤害、起始能量、护盾和幸运。
- 隐藏信号羁绊要求铃的关系值达到二级，形成从剧情选择到战斗构筑的闭环。
- 关卡重置会重新计算共鸣；战斗 HUD、暂停战术中心和最终构筑战报均显示或记录结果。
