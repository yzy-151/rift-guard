# 模式一：裂隙守望 V2

## 已实现

- 当前五分半塔防肉鸽被登记为首个正式模式，数据入口为 `game/data/v2/modes.json`。
- 所有可叠加 Buff 取消层数上限，卡面显示 `当前层数 N / ∞`。
- 卡库从 100 张扩充到 116 张，每逢水晶 3 的倍数等级保底出现机制卡。
- 新机制包含多弹道、近战追加斩击、贯穿、连锁、范围爆炸、追击、处决、死亡爆破、精英增伤、击杀攻速成长。
- 新增角色02与角色03的局内增援卡，仍遵守场上最多三人的规则。
- 新增赤月炮击、交叉火力、潮汐急救、终幕齐射四类周期场外支援。
- 新增斩击序列、强化弹道、冲击环、爆炸射线、支援提示与屏幕震动。
- 模式一开场、胜利和失败均触发剧情；对话使用黑红漫画式构图、立绘回弹入场、文字快速显隐与短促提示音。

## 素材许可

- Cethiel 的 Weapon Slash - Effect：CC0。
- Reactorcore 的 Gun Muzzle Flash Effects：CC0。
- Helltaker 仅作为节奏与构图参考，项目未提取、复制或分发其原始美术和音频。

## 验证

- 数据库、动态卡池、无限叠加、机制卡、增援角色、核心循环、旧战斗兼容、旧奖励兼容、剧情与五分钟平衡测试通过。
- 五分钟平衡回归结果：330 秒通关，水晶生命 100，13 次强化选择，138 击杀。
