# Rift Guard V52 发布说明

V52 聚焦战斗画面可读性、角色与怪物素材收口、无尽模式性能和完整音频反馈。

## 主要变化

- Boss 血条缩短为 560×46 的顶部居中组件，填充条运行时高度为 9 像素，名称、阶段、生命百分比和护盾保持可读。
- Boss HUD 的面板、名称、填充条和数值区域全部进入 `data/ui_layout_profile.tres`，可继续通过 UI 实验台调整。
- 芙宁娜只使用 `assets/characters/sequences/hero_03` 新序列，旧立绘、旧骨骼和旧 AI 帧资产已移除。
- 旅行者与芙宁娜显示尺寸调整为 106%，希露菲恢复原尺寸，皮卡超人在上一版基础上再放大 1.5 倍。
- WASD 移动不再生成鼠标点击反馈；队友沿旅行者轨迹延迟启动和停止。
- 底部角色 HP 与能量条缩窄；攻击与命中新增独立音效，关卡进入、剧情和各类按钮统一接入 Helltaker 音效反馈。
- 哥布林茅房单次生成一个哥布林，生成周期延长并限制存活数量；无尽模式限制低级怪和茅房数量，增加高阶敌人替换，并在高负载时压缩特效预算。
- 地面怪物可持续绕过墙体，不再在障碍前堆积。
