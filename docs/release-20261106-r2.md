# 裂隙守望 · 三章试玩版

版本：2026.11.6.2 · 2026-11-06

## 游玩内容

- 选关页展示全部8关及缩略图，普通模式开放第1—3关、按顺序解锁；第4—8关固定标为暂未开放，旧存档同样不可解锁。
- 初始只有旅行者，第一关出发剧情后芙宁娜加入，第一关结束后通过格温的迎接剧情招募格温。
- 第一关保留原有起床过场与作者剧情；润色芙宁娜初遇、格温招募、第二和第三关对话与结尾，以烧水壶和寻找出口串联剧情；成功/失败、招募和部署分支逻辑保持。
- 第三关结束可回到主菜单，或携带当前队伍和构筑继续无尽模式。
- 保留植物机关、卡牌构筑、角色图鉴、家园和示范工坊。
- 阿米娅主题新图标、启动插画、加载提示和淡入动画。
- 暂停菜单的操作说明不再发放调试卡牌，发布版关闭特效预览快捷键。

## 下载与操作

`RiftGuard.exe` 是 Windows x64 单文件版，双击即可玩，不需要安装 Godot。

`RiftGuard-Android.apk` 是签名安装包，包含 arm64-v8a 与 x86_64，安装后横屏游玩；包名 `com.riftguard.demo`，可与旧测试版共存。

| 操作 | Windows | Android |
| --- | --- | --- |
| 部署角色 | 拖动底部角色卡到战场 | 按住角色卡并拖到战场 |
| 移动 | 右键目标位置 / WASD | 先点“移动”或“全队移动”，再点目标位置 |
| 技能 | Q / E，或技能按钮 | 点击技能按钮，指向性技能再点目标 |
| 购买机关 | 点击植物商店，选种类后放到空格 | 同左 |
| 暂停 | 空格 / Esc / 暂停按钮 | 暂停按钮 / 系统返回键 |
| 全屏 | F11 / 设置 | 自动横屏全屏 |
| 家园 | WASD / 方向键，交互键 | 屏幕方向按钮与“交互”按钮 |

安卓切后台会暂停进行中的战斗，返回后由玩家继续；系统返回键优先关闭设置、图鉴或瞄准，不会替玩家选剧情分支。

## 源码与构建

工程入口 `game/project.godot`，Godot 4.4.1，Compatibility渲染器；UI逻辑尺寸1280×720并保持比例缩放。

Windows导出使用 `Windows Desktop` 预设；Android导出使用 `Android` 预设，需要JDK17、Android SDK及Godot4.4.1导出模板。

安卓签名密钥不在仓库中，构建时通过 `GODOT_ANDROID_KEYSTORE_RELEASE_PATH`、`GODOT_ANDROID_KEYSTORE_RELEASE_USER` 和 `GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD` 环境变量注入；更新已安装的试玩版必须使用同一密钥。

发布分支保留当前本地累计开发成果，独立于历史v100分支；不改写历史版本。
