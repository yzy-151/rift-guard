# V100 发布验证

V100 将本轮已完成的经典玩法、漫画音画、家园／无尽和自由工坊汇总为 `100.0.0`。Godot 4.6 Windows 发布模板与资源 PCK 放在同一压缩包，保留 V86 角色／怪物素材和剧情二选一原框。

发布构建使用 `tools/build_v100.ps1`。实际发布包通过原生入口执行模拟、暂停、剧情、爆炸、战斗结束、经典资源覆盖和性能场景；详细退出码、断言数与文件 SHA256 记录在 `release-report.json`。历史测试参数中的 V94／V95 表示检查最初引入的版本，测试对象为 V100 EXE/PCK。

本次发布包的 528 项检查通过：模拟 78、暂停 72、剧情 42、爆炸 129、战斗结束 111、经典内容与打包资源 96。七个独立进程（含性能场景）退出码均为 0，未检出脚本／运行时错误。实际发布版截图见 [二选一](release/choices.png) 和 [暂停页](release/pause.png)。

本次只进行版本与发布整理；此前的实机预览、玩法变更和受控性能对照保留在 [V95 验证目录](../v95-validation/README.md)。发布包测试使用隔离 QA 存档，不覆盖玩家进度。

构建输出位于 `releases/V100/`，属于本地正式交付物，通过 GitHub Release 下载；源码仓库不包含可执行文件和资源包。
